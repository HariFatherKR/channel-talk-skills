# 다른 언어 설정

Source: https://docs.channel.io/help/ko/articles/%EB%8B%A4%EB%A5%B8-%EC%96%B8%EC%96%B4-%EC%84%A4%EC%A0%95-f6b84106

채널톡의 번역 기능을 통해 채널톡에서 설정하는 문구를 한국어, 영어, 일본어 포함하여 총 32가지 국가의 언어로 설정 가능합니다.

## Body

채널톡은 고객이 접속한
브라우저 언어 및 기기 설정
에 따라 자동으로 보여지는 언어가 변경됩니다.
번역 설정이 가능한 기능
채널 프로필
프로필 번역을 통해 한국 고객들에게는 한국 채널명으로, 외국 고객들에게는 해당 국가의 언어로 채널 프로필을 설정할 수 있어요.
설정 경로: [채널 설정] - [일반 설정] - [채널 프로필] - [번역]
봇 프로필
채널의 자동 메시지를 전달하는 봇의 이름도 언어별로 설정이 가능하고, 이미 생성된 봇은 번역을 추가할 수 없어요.
설정 경로: [채널 설정] - [팀원 구성] - [봇] - [새 봇 추가하기] - [번역]
라벨 버튼
고객이 사이트에 처음 방문했을 때 나타나는 라벨 버튼도 다양한 언어로 설정해보세요.
설정 경로: [채널 설정] - [일반 설정] - [버튼 설치 및 설정] - [웹 버튼 설정] - [라벨 버튼] - [번역]
인사말
채널톡 채팅버튼을 눌렀을 때 고객에게 보여지는 인사말이에요. 언어 별로 잘 설정하여 고객 문의를 유도해보세요.
설정 경로: [채널 설정] - [인사말] - [번역]
부가 서비스 활용
부가 서비스인
워크플로우
를 통해 고객에게 자동 메시지를 보낼 수 있고, 두 기능의 메시지는 모두 자동으로 번역되어 노출되지 않아요. 따라서, 국가 혹은 언어로 필터링 후 원하는 메시지를 직접 입력해주세요.
워크플로우 예시
워크플로우를 만들 때, 필터링 부분에
국가
나
언어
를 설정해주시면 해당 서포트봇이 해당 국가 혹은 언어로 접속한 고객에게만 보여지게 됩니다.
(→ 워크플로우 가이드 확인하기)
국가의 기준: IP 기반으로 접속 위치 추정
언어의 기준: 유저가 접속한 브라우저의 언어
다른 언어 메시지 번역 보기
고객
고객의 언어와 매니저가 보낸 메시지 언어가 다른 경우 고객이 메시지에 마우스를 올리면 '번역 보기' 옵션이 제공됩니다.
팀 멤버
고객 혹은 팀 멤버가 보낸 메시지가 내 언어와 다른 경우 발신자 프로필 우측에 '번역 보기' 옵션이 제공됩니다.
번역 보기 위치 변경 안내(2026-02-13)
번역 보기 위치가 메시지 하단에서 프로필 우측으로 변경되었으니 참고해 주세요.
스크립트로 언어 고정
웹빌더사(카페24, 아임웹 등)의 경우에는 스크립트를 수정하여 언어 고정이 어려울 수 있어요.
채널톡 언어를 한 가지로 고정하여 보여지도록 하는 방법도 있어요. 이 경우, 스크립트 수정이 필요합니다. 채널톡 설치 스크립트에서 language 설정을 en(영어), ko(한국어), ja(일본어)로 변경해주세요.
라벨 버튼, 프로필, 인사말, 봇 메시지
언어가 설정해주신 하나의 언어로 고정됩니다.
ChannelIO('boot', {
"pluginKey": "YOUR_PLUGIN_KEY",
"language": "ko",
});
관리자 언어 변경
관리자 화면의 언어도 변경이 가능하고, 이 때에는
한국어, 영어, 일본어
가 지원됩니다.
설정 경로: [개인 설정] → [계정 설정] → [언어]
