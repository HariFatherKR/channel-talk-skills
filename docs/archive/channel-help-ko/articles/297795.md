채널톡 번호를 기존 고객센터 번호 또는 기존 유선 전화기와 연동해서 사용해보세요.

기존 번호 연동
신규 070 번호를 먼저 발급 받고, 기존 번호와 연동 작업을 진행해주세요.

1. 대표 번호를 이용 중이라면? (1588,1644 등)
수신자부담번호(080), 안심번호(050X)도 성격이 비슷한 번호라 절차가 동일합니다.
A케이스
전국 대표 번호에 채널톡 070 번호 연동 (권장)
전국 대표 번호의 통신사 고객센터를 통해 채널톡 070 번호 연동을 요청해주세요.
대표 번호에 채널톡 070 번호 등록 시 필요한 서류(통신서비스 가입증명원)는 채널팀에 요청하여 수령 가능합니다.
(→ 채널팀에 서류 요청하기)
B케이스
단말기 착신 전환
기존 물리 전화기에서 직접 착신전환을 설정하실 수 있습니다.
미트 설정 및 테스트 시 사용해보실 수 있으나, 미트 도입이 결정되면 A 케이스로 연동 후 이용해주시는 것을 권장드립니다.
직접 착신전환을 설정하시는 경우 전화를 수신할 때도 '착신 전환으로 인한 발신 통화료'가 발생할 수 있으며, 가입하신 통신사 요금제에 따라 달리 적용됩니다.
2. 일반 번호(02,031 등), 인터넷 번호(070), 핸드폰 번호(010)
일반 번호, 인터넷 번호의 경우
통신사에 별도 요청 없이 기존 물리 전화기에서 채널톡 번호로 직접 착신전환을 설정 하실 수 있습니다.
직접 설정이 어렵다면, 기존 가입 통신사에
타 통신사 번호(채널톡070)로
착신전환하는 방법을
문의해주세요.
핸드폰 번호의 경우
통신사의 착신전환 부가서비스를 통해 채널톡 070번호로 착신전환 하실 수 있습니다.
통신사 측 부가서비스 비용이 별도로 발생할 수 있습니다.
직접 착신전환을 설정하시는 경우 전화를 수신할 때도 '착신 전환으로 인한 발신 통화료'가 발생할 수 있으며, 가입하신 통신사 요금제에 따라 달리 적용됩니다.
채널톡에서 일반 번호 사용이 가능하도록 통신사와 협의 중이니 참고부탁드려요.
기존 번호로 전화 걸기↗️ (발신 번호 변경)
이용중인 전화 서비스에 따라 연동 방법 및 이용 금액에 차이가 있습니다. 현재 이용하시는 전화 서비스에 따라 착신 전환 신청 및 통신 가입 증명원을 발급받아 채널팀에 전달해주세요.
(→ 발신 번호 변경 신청하기)
010 번호는 발신 번호로 변경이 불가합니다.
[채널 설정] - [미트] - [전화] 탭에서 등록된 전화번호 우측의 수정 버튼을 눌러 기존 번호 연결을 할 수 있습니다.
연동 신청 후 필요 서류를 제출해주세요. 채널팀에서 확인 후 승인이 완료됩니다.
연동을 위해서는 통신가입증명원을 통신사에서 발급받아주셔야 합니다.
제출 서류 확인 후 승인까지 최대 일주일의 시간이 소요됩니다.
유선 전화기 연동
연동 기본 개념 이해하기
채널톡 전화를 유선 전화기에서 걸고 받을 수 있어요.
유선 전화기 연동 후에도 전화가 울리는 기기(PC/모바일/전화기)를 선택할 수 있어요.
SIP 연동을 지원하는 전화기라면 연동이 가능해요.
SIP란?
"Session Initiation Protocol"의 약자로, 실시간 통신을 위해 약속된 통신 방식을 뜻해요. 쉽게 말해 채널톡과 유선 전화기가 서로를 인식하는 신호에요.
A 팀 멤버에게 할당할 가상의 전화기를 등록하고
등록된 가상 전화기와 유선 전화기를 연동하면
A 팀 멤버에게 배정된 채널톡 전화가 유선 전화기에도 울리게 돼요
대표적인 상황
채널톡 전화번호 1개
유선 전화기 수 = 가상 전화기 등록 수 = 전화 상담 팀 멤버 수
유선전화기가 여러개면 번호를 여러개 발급받아야 할까?
아니에요! 전화번호 개수와 연동할 전화기 수는 무관해요.
채널톡 번호 1개로 여러 팀 멤버가 통화를 진행할 수 있듯, 여러 유선 전화기를 연동할 수 있어요.
채널톡 전화번호가 여러개 필요한 경우
특정 상담원/상담팀 전용 번호가 필요할 때
텔레마케팅 등 아웃바운드 콜을 위한 전용 번호가 필요할 때
세일즈 직원 전용 직통 번호가 필요할 때
연동 방법 요약

등록된 가상 전화기의 SIP 연동 정보 확인
실물 전화기 SIP 설정 화면에서 가상 전화기의 SIP 연동 정보를 입력하면 연동 완료!

유의사항(필독)
기존 통신사의 번호가 부여된 유선 전화기
에는 채널톡 전화 연동을 시도하지 말아주세요.
기존 통신사 번호가 부여되어있는 전화기는 SIP 설정 시도 시 아래와 같은 문제가 발생할 수 있습니다. (현재 실사용 여부와 관계 없음)
❗️SIP 설정 관리자 페이지에 접속이 안될 수 있습니다.
❗️채널톡 연동 설정 완료 후에도 연동이 끊어질 수 있습니다.
❗️기존 전화번호 계정이 변경되어 사용이 불가하게 될 수 있습니다.
❗️인터넷의 설정을 임의로 변경하게 되어 인터넷 사용이 끊어질 수 있습니다.
SIP 설정을 변경해도 무방한 전화기를 사전에 구비해 주세요.
휴대전화 개통으로 비유하면, 셀프 개통을 위한 공기계가 필요한 것과 비슷해요.
*실수로 기존 전화기에 연동을 시도하여 위와 같은 문제가 발생한 경우, 통신사에 연락하여 원상복구를 요청해주세요.

## FAQs

### SIP 연동을 지원하는 전화기인지 어떻게 확인하나요?

인터넷 전화기는 대부분 SIP 연동을 지원하지만 전화기의 정확한 스펙은 제조사 상세 설명서를 확인해주세요.

설명서 내 SIP Protocol 에 대한 설명 항목이 있다면 연동이 가능합니다.

모델 별 상세 설명서는 제조사 홈페이지에서도 확인하실 수 있어요.


연동 가능한 누리보이스(구 모임스톤) 모델 (및 OS 버전)
- IP215(S) (1.30.351)
- IP355 (1.10.014)
- 확인 시 마다 추가 예정
홈페이지: http://nurivoice.com/wvs/

Poly(구 Polycom) 홈페이지: https://www.hp.com/kr-ko/poly/phones/desk-phones.html

### 확인한 IP주소로 접속이 되지 않아요.

IP 주소가 https를 지원하지 않아 접속되지 않을 수 있습니다.
s를 지우고 http:// 뒤에 IP 주소를 붙여 접속해보세요

폴리의 경우 https로만 접속을 제한하는 경우도 있으나, 브라우저에서 접속을 제한하면 접속이 불가할 수 있습니다.
이 경우, 아래와 같이 설정 후 재시도 해보세요.

LCD 설정 화면에서 웹 서버 구성 요소를 설정하는 방법
1. 설정 - 고급 - 암호입력(123) - 관리자 설정 - 웹 서버 구성 - 웹 서버 켜짐 확인
2. 설정 - 고급 - 암호입력(123) - 관리자 설정 - 웹 서버 구성 - 웹 구성 모드 → HTTP/HTTPS 로 설정 - 뒤로 - 구성 저장 - 선택 → 재시동
3. 이후 http로 접속 재시도

### 누리보이스(모임스톤)의 관리자 계정이 틀렸다고 나와요

연동을 위해 필요한 것은 관리자계정이 아닌 사용자 계정입니다.
사용자 계정 설정 화면 접속을 위한 초기 계정은 아래와 같아요
id: user
password: 0000

전화기 설정 쪽의 관리자 계정은 연동 과정에는 필요하지 않아요.
별도 설정이 필요하신 경우 아래 초기 계정으로 접속을 시도해보세요
id: admin
password: 9999

계정 초기 id와 비밀번호를 수정하지 않았는데 접속이 안된다면 초기 계정이 다른 모델일 수 있어요. 이럴 경우, 유선 전화기 제조사에 문의해주세요.

### 유선 전화기에 있는 다이얼 및 기능 버튼들을 사용할 수 있나요?

유선 전화기의 다이얼(숫자) 버튼은 사용하실 수 있어요.

단, 재다이얼, 통화 전환, 보류 등의 기능 버튼들은 채널톡과 상호작용하지 않아요. 

추후 전화기 기능 버튼 상호작용도 제공할 수 있도록 준비중입니다.

### 유선 전화기에서 국제전화를 걸 수 있나요?

+(플러스) 기호를 입력한 후 국가번호와 상대방 번호를 입력하면 가능합니다.
단, +(플러스)기호를 입력할 수 없는 전화기라면 해당 전화기로는 국제전화를 발신 할 수 없어요. 그럴 경우 채널톡 PC 또는 모바일 어플에서 국제전화를 이용해주세요.

*채널톡 전화는 001, 002, 005 와 같은 국제 전화 서비스 번호는 지원하지 않습니다.

### 유선 전화기 연동하려면 별도 요금이 발생하나요?

유선 전화기를 채널톡 전화기와 연동하더라도 별도 요금이 청구되지 않습니다.
다만, 연동에 필요한 유선 전화기가 없다면 전화기 구매 비용이 별도로 발생할 수 있어요.

채널톡 전화 이용에 따른 실비(전화 번호 발급 비용, 발신 통화료)는 사용량에 따라 발생합니다.

### 유선 전화기도 채널톡에서 살 수 있나요?

채널톡은 유선 전화기를 별도로 판매하지 않습니다.
가이드에 안내된 제조사 등 SIP 설정이 가능한 유선 전화기를 별도로 구매하여 준비해주세요.

### 유선 전화기가 고장나면 어떻게 하나요?

채널톡은 유선 전화기에 대한 A/S를 제공하지 않습니다. 유선 전화기에 고장이 발생하거나, 소모품(수화기, 전원 코드, 랜선 등) 일체가 필요한 경우 전화기 제조사에 문의해주시기 바랍니다.
