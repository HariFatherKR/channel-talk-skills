# 구글 스프레드시트

Source: https://docs.channel.io/help/ko/articles/%EA%B5%AC%EA%B8%80-%EC%8A%A4%ED%94%84%EB%A0%88%EB%93%9C%EC%8B%9C%ED%8A%B8-c975a8c9

ALF 태스크 함수 단계에서 구글 스프레이드시트를 읽고 수정할 수 있는 기능을 제공합니다.
시트 맨 아래에 새 행 추가, 지정된 행을 새 값으로 덮어쓰기 등 다양한 작업을 자동화할 수 있습니다.

## Body

사용 방법
앱스토어 앱 설치하기
[채널 설정] - [연동] - [앱스토어]에서 Google Spreadsheet 앱을 설치해 주세요.
구글 계정 연동하기
[연동하기]를 눌러 구글 계정을 연동해주세요.
연동 완료되면 연동 날짜가 표시됩니다.
함수 단계 설정
[AI → 설정 → 태스크] 단계에서 '함수'를 클릭해주세요.
함수 단계에서 보여지는 목록 중 원하는 함수를 선택해주세요.
[함수 목록]
append_row
시트 마지막에 새 행 추가
추가된 행의 위치 반환
get_rows_by_index
지정된 행 범위의 데이터를 2차원 배열로 반환
get_row_by_key
지정된 컬럼에서 키 값과 일치하는 첫 번째 행 반환 (중복 시 warning 포함)
get_row_count
시트의 데이터가 있는 총 행 수 반환 (A:ZZ 범위 기준)
update_row_by_index
지정된 행을 새 값으로 덮어쓰기
update_row_by_key
키 값으로 행을 검색하여 첫 번째 매칭된 행을 업데이트 (중복 시 warning 포함)
delete_rows_by_index
지정된 행 범위를 삭제. 삭제된 행 수 반환
delete_row_by_key
키 값으로 행을 검색하여 첫 번째 매칭된 행을 삭제 (중복 시 warning 포함)
list_sheets
스프레드시트 내 모든 시트 정보 조회
list_spreadsheets
Google Drive에서 접근 가능한 스프레드시트 목록 조회
folderId가 있으면 해당 폴더 내로 필터링
