목록에서 태그 이름 수정 후, 고객에게 부착되어 있던 기존 태그도 수정된 태그 이름으로 한 번에 변경할 수 있어요.
병합하기
고객 태그 병합은 선택한 태그를 다른 태그로 합치는 기능이에요. 이 때 선택된 태그의 하위 태그까지 포함하여 병합됩니다.
목록에서 태그 병합 후, 고객에게 부착되어 있던 기존 태그도 한 번에 삭제하고 병합한 새로운 태그를 부착할 수 있어요.

태그를 선택하여 삭제할 수 있어요. 상위 태그를 삭제하면 하위 태그도 함께 삭제됩니다.
목록에서 태그 삭제 후, 고객에게 부착된 태그도 한 번에 삭제할 수 있어요.

## FAQs

### 삭제된 상담 태그가 다시 생성돼요.

워크플로우에 삭제하려는 상담 태그를 추가하는 액션이 설정되어 있다면, 워크플로우에 의해 태그가 다시 생성 및 추가 됩니다. 그래서 먼저 워크플로우 액션에서 설정된 해당 태그를 삭제해야 다시 생겨나지 않아요.

### 고객 태그 이름 변경 시 기존 고객 태그에 일괄 적용 방법은 어떻게 되나요?

다음 두 가지 방법으로 기존 고객에게도 일괄 적용할 수 있어요.
1. 고객 태그 관리 페이지에서 설정
- 목록에서 고객 태그 이름 변경 후
- 고객에게 부착된 기존 태그 이름도 함 수정할지 물어보는 모달에서 일괄 적용을 선택
2. 고객 연락처에서 고객 선택 후 변경
- 고급 필터로 고객 태그(tags)가 ‘기존 태그 이름’과 ‘하나라도 해당되는’ 고객을 검색
- 변경하고 싶은 고객을 선택
- 테이블 위 우측 ‘태그 설정’ 아이콘 클릭
- 기존 태그는 체크 해제, 새로운 이름의 태그를 추가 혹은 체크 후 저장

### 고객 태그는 몇 개 까지 만들 수 있나요?

고객 태그는 총 1,000개 까지 만들 수 있고, 한 고객에게 최대 20개의 상담 태그를 부착할 수 있습니다.

### 워크플로우 등으로 입력되는 고객 태그가 20개가 넘어가면 어떻게 동작하나요?

20개 이후에 달리는 태그는 반영되지 않고, 먼저 달려있는 20개 태그만 적용됩니다.

### 상위 태그 이름 변경 시 모든 하위 태그도 같이 이름이 변경돼요

상위 태그의 이름을 변경하면 하위 태그의 이름까지 함께 변경됩니다. 단, 목록에서 태그 이름을 변경한다고 해서 기존 고객에 달려있던 태그까지 수정되지는 않아요.
목록에서 태그 이름 수정 후 고객에게 달린 태그도 이름을 수정할지 물어보는 모달에서 기존 고객에 달려있던 태그도 함께 이름을 수정할 수 있어요.

### 고객태그 상위 태그 삭제 시 모든 하위 태그도 같이 삭제돼요

상위 태그를 삭제하면 하위 태그까지 함께 삭제됩니다. 단, 목록에서 태그를 삭제한다고 해서 기존 고객에 달려있던 태그까지 삭제되진 않아요.
목록에서 태그 삭제 후 고객에게 달린 태그도 삭제할지 물어보는 모달에서 기존 고객에 달려있던 태그도 함께 삭제할 수 있어요.

### 상위 태그는 남겨두고 하위 태그만 삭제하고 싶어요

다음 두 가지 방법으로 상위 태그는 남겨두고 하위 태그만 삭제할 수 있어요.
1. 원하는 하위 태그만 선택하여 삭제
- 고객 태그 관리 목록에서 태그 이름 순(오름차순/내림차순)으로 정렬해 주세요.
- 상위 태그 이름 앞의 '>' 를 클릭 후 하위 태그 목록을 펼쳐 주세요.
- 원하는 하위 태그를 선택해 삭제할 수 있어요.  [A] 상위 태그 목록에서 → [A/1], [A/2]만 선택 후 삭제
- 삭제 후, 기존 하위 태그가 부착된 고객에게서 해당 태그를 삭제하거나 그대로 남겨둘 수 있어요.
2. 상위 태그와 병합하여 삭제
- 삭제하고자 하는 상위 태그와 하위 태그를 전체 선택해 주세요.
- 병합하기를 눌러 상위 태그로 병합할 수 있어요.  [A], [A/1], [A/2] 선택 → [A]로 병합
- 병합 후, 기존 하위 태그가 부착된 고객에게 병합된 상위 태그가 부착되도록 변경하거나 그대로 남겨둘 수 있어요.

### 고객 태그 이름을 다른 이름으로 수정할 수 있나요?

이미 존재하는 태그 이름으로는 수정할 수 없어요, 하지만 병합 기능을 통하여 고객 태그를 다른 태그명으로 통합할 수 있습니다.

ex1) [A], [A/1], [A/2] 고객 태그를 이미 존재하는 [B], [B/1], [B/2]로 합쳐야하는 경우
- 하위 태그 부터 병합하여 합칠 수 있습니다.
[A/1] → [B/1], [A/2] → [B/2]를 먼저 합친 뒤 [A] → [B]으로 병합이 가능합니다.

ex2) [A], [A/1], [A/2], [B] 고객 태그가 있을 때, [A], [A/1], [A/2]를 [B] 태그 하위로 넣고 싶은 경우
- 하위 태그가 없을 때에는 바로 이름 수정이 가능합니다.
[A/1] → [B/1], [A/2] → [B/2]로 이름을 수정합니다.
- 하위 태그를 옮긴 후 병합하여 합칠 수 있습니다.
[A] → [B]로 병합이 가능합니다

### 상위 태그를 하위 태그로 합칠 수 있나요?

네, 상위 태그도 하위 태그로 합쳐질 수 있어요. 예를 들어 고객 태그 [재입고요청]을 [재입고요청/안내완료]라는 하위 고객 태그로 합칠 수 있습니다.
