# 커스텀 리포트 만들기

Source: https://docs.channel.io/help/ko/articles/create-custom-report-db2f47c4

커스텀 리포트 제작 방법에 대한 가이드입니다. 대표 예시를 통해 리포트를 만들고, 차트를 추가하는 것까지 확인할 수 있습니다.

## Body

🏁 영상으로 배우고 싶다면?
커스텀 리포트는
원하는 지표를 직접 조합해 자유롭게 나만의 통계 리포트를 만드는 기능
이에요.
커스텀 리포트에서는 하나의 리포트 안에 여러 개의 차트를 추가해 주요 지표를 한 눈에 확인할 수 있습니다.
커스텀 리포트는
플랜 별로 리포트 생성 개수가 달라집니다.
이를 참고해서 이용해주세요.
무료 플랜, 얼리 스테이지 플랜: 리포트 생성 불가
그로스 플랜: 최대 2개
엔터프라이즈 플랜: 최대 1000개
이 가이드에서는 고객센터 운영 시 가장 자주 확인하는 대표적인 차트 2가지를 예시로 차트를
처음부터 끝까지 만드는 방법
을 단계별로 설명해드릴게요.
커스텀 리포트 만들기
[분석] - [상담 통계] - [커스텀 리포트] 화면으로 접속 후 우측 상단의 [+리포트 만들기] 클릭
미리 생성된 템플릿을 적용하거나, 새로 만들기를 통해 처음부터 생성할 수 있어요.
리포트에 차트 추가하기
리포트는 2가지 방법으로 구성할 수 있어요.
① 생성된 리포트 우측 화면에서 [새로 만들기] 를 클릭하여 차트를 새로 추가하거나
② 또는 [
커스텀 리포트 레시피
]을 통해 새로 생성할 필요없이 대표적으로 많이 확인하는 데이터를 바로 리포트로 확인해볼 수 있습니다.
리포트 당 차트는 최대 30개까지 추가가 가능합니다.
이제부터는 [새로 만들기]를 통해 차트를 0부터 1까지 만드는 방법을 알려드릴게요.
제공되는 다양한 차트 중 목적에 맞는 필요한 차트를 선택하여 리포트를 구성할 수 있어요.
차트 별 사용 목적과 상세 설명은 차트 유형 및 옵션 가이드에서 참고해주세요. (
→ 가이드 확인하기
)
일별 상담 인입 추이를 한 눈에 보는 라인 차트 만들기
1단계. 차트 추가 → 새로 만들기
리포트에 접속 후 우측의 [새로 만들기] 항목 중
라인 차트
를 선택합니다.
2단계. 지표 설정
우측 메뉴 중
지표
에서 인입된 상담 수를 선택합니다.
3단계. 필터와 추가 지표, 가로축, 차트 그룹 설정
지표를 추가하거나 필터를 걸고, 가로축과 차트 그룹 설정에 따라 자유롭게 차트를 구성해볼 수 있습니다.
필터:
원하는 팀이나 상담 태그 등 원하는 값만 확인할 수 있어요.
추가 지표:
다양한 지표를 하나의 차트에서 확인할 수 있도록 추가가 가능해요.
가로축:
차트 가로축에서 보여질 데이터를 선택할 수 있습니다.
상담 태그로 선택 시, 원하는 태그만 가로축에 포함될 수 있도록 필터링이 가능해요.
차트 그룹:
각 데이터를 원하는 그룹으로 묶어서 확인할 수 있어요.
상담 태그로 선택 시, 원하는 태그만 차트 그룹에 포함될 수 있도록 필터링이 가능해요.
예시1) 팀 별 상담 인입 수 확인하기
지표: 인입된 상담 수 선택
필터링: 팀 필터링 - 채팅팀
지표 추가: 인입된 상담 수 선택
필터링: 팀 필터링 - 전화팀
가로축: 시간 선택
차트 그룹: 없음
예시2) 여러팀을 한 번에 확인하기
지표: 인입된 상담 수 선택
가로축: 시간 선택
차트 그룹: 팀 선택
4단계. 차트 옵션 설정
동일 전기간과 비교
통계를 확인하는 기간을 선택 시, 동일한 전기간과의 데이터 차이를 비교합니다.
예를 들어 7일로 기간을 설정 시, 이전 7일의 데이터와 비교합니다.
데이터 레이블
차트의 각 데이터 포인트에 실제 수치 값을 함께 표시합니다.
목표 표시
직접 목표를 설정하고 비교할 수 있습니다.
5단계. 저장
차트 제목을 입력 후 저장을 클릭합니다.
차트 저장 후 꼭 리포트 저장까지 마쳐주세요.
상담 만족도를 확인하는 CSAT 테이블 만들기
1단계. 차트 추가 → 새로 만들기
리포트에 접속 후 우측의 [새로 만들기] 항목 중
테이블
을 선택합니다.
2단계. 지표 설정
우측 메뉴 중
지표
에서 CSAT 점수(%)를 선택합니다.
3단계. 지표 추가
지표 추가를 통해 CSAT의 상세 점수를 확인할 수 있도록 구성할 수 있어요.
지표 추가 클릭 후 [CSAT 응답]을 선택하고, 우측의 [개수]를 선택합니다.
상세 점수를 더 추가하고 싶다면
CSAT 점수 별 분포를 확인하고 싶다면 지표를 더 추가하여 테이블에 값을 추가할 수 있어요.
제목 수정: 5점
지표 추가: [CSAT 응답], [개수] 선택
필터링: CSAT - 다음과 일치 - 5
이 방식으로 5~1점까지 점수를 추가할 수 있습니다.
4단계. 행기준 설정
행기준을 변경하여 담당자별 / 담당팀별 / 상담태그별 CSAT 점수를 확인할 수도 있어요.
리포트 배치하기
생성한 차트는 드래그를 통해 원하는 위치로 옮기고, 크기를 조정할 수 있습니다. 원하는 배치로 리포트를 구성해보세요!
커스텀 리포트 저장
리포트 구성까지 마쳤다면 꼭 저장을 눌러주셔야 생성한 차트와 구성한 내용이 저장됩니다. 잊지말고 리포트의 이름을 설정하고, 저장해주세요.
커스텀 리포트 채널간 복제하기
여러개의 채널을 운영 중이시라면, A채널에서 생성한 커스텀 리포트를 B채널로 가져올 수 있습니다. 공들여 만든 커스텀 리포트를 필요한 다른 채널에도 쉽게 적용해보세요.
내보내기
복제할 커스텀 리포트가 존재하는 A채널의 [분석] - [커스텀 리포트]에서 복제할 커스텀 리포트를 선택합니다.
커스텀 리포트 화면의 우측 상단 더 보기(...) 클릭 후 '내보내기'를 누르면 파일이 저장됩니다.
가져오기
커스텀 리포트를 가져올 B채널로 접근한 후 [분석] - [커스텀 리포트] - [+리포트 만들기] - [가져오기]를 클릭합니다.
A채널에서 다운로드 받은 파일을 업로드하면 가져오기가 완료됩니다.
커스텀 리포트 생성 팁
하나의 리포트에는 여러개의 차트를 추가할 수 있어요.
[컴포넌트: 텍스트 박스]를 통해서 리포트의 가독성을 더 높여보세요.
리포트 상단의 기간 필터를 변경하면 리포트 내 모든 차트에 공통으로 적용됩니다.
동시 편집: 동일 리포트를 여러 사용자가 동시에 수정하는 경우, 마지막 저장 시점을 기준으로 최종 상태가 덮어씌워집니다.

## FAQs

### 커스텀 리포트의 필터는 최대 몇개까지 추가할 수 있나요?

커스텀 리포트 내의 필터는 최대 10개까지 추가가 가능합니다.

### 커스텀 리포트에서 리포트와 차트 각각에 필터를 설정할 수 있는데 어떻게 동작하나요?

리포트와 리포트 내의 차트에 필터가 모두 설정되어 있을 경우 AND 조건으로 동작하게 됩니다.

### 커스텀 리포트의 [인입된 상담수]와 [응답을 시작한 상담 수]의 차이는 뭔가요?

- 인입된 상담수: ALF에게 처음 질문을 남기거나, ALF를 사용하지 않는 경우 상담이 열리는 시점을 의미합니다.
- 응답을 시작한 상담수: 수신함에 상담이 인입된 후 담당자가 배정되고, 담당자가 첫 답변을 진행한 시점을 의미합니다.

예를 들어, 금요일 밤에 고객이 문의를 남기고 월요일 아침에 상담원이 답변을 했다면 
1) 인입된 상담수는 금요일 밤으로 집계되며
2) 응답을 시작한 상담수는 월요일 아침으로 집계됩니다.
