# 전화 모니터링

Source: https://docs.channel.io/help/ko/articles/%EC%A0%84%ED%99%94-%EB%AA%A8%EB%8B%88%ED%84%B0%EB%A7%81-3189edd5

실시간으로 전화 상담을 모니터링하며 상담 인원을 조정하거나 전화 상담을 효율적으로 운영해 보세요.

## Body

오퍼레이션 권한이 있는 팀 멤버만 조회할 수 있습니다.
(→ 권한 설정하기)
전화 모니터링이란?
수발신한 전화 상담의 응대, 부재중 건수를 확인할 수 있고, 전화 상담에 참여하고 있는 상담원의 상태를 한눈에 확인할 수 있는 대시보드에요.
실시간으로 대기 중인 콜 수, 통화중인 상담원 수를 비교해보면서 상담인원을 조정하거나 전화 상담을 효율적으로 운영해 보세요.
지표 설정
전화 모니터링을 확인하기에 앞서, 지표의 세부 항목을 설정하여 목표를 세워보세요.

의 사유 별 통계 포함 여부와
서비스 레벨 및 응답 속도 준수율
의 목표 시간을 설정할 수 있어요.
지표 설정 값은 채널 단위로 저장되어 채널에 속한 모든 상담원이 동일한 지표를 확인할 수 있어요.

부재중 사유

운영시간 아님
: 미운영시간에 걸려와 끊어진 전화를 포함/제외
고객의 전화 종료
: 연결 도중 고객이 끊어서 종료된 전화를 포함/제외
링 시간 초과
: 상담원 배정 후 링 시간이 초과하여 종료된 전화를 포함/제외
모든 상담원 미트중
: 전화를 받을 수 있는 상담원이 없어 종료된 전화를 포함/제외
최대 대기열 수 초과
: 대기열이 200건을 초과하여 종료된 전화를 포함/제외
대기열 최대 대기시간 초과
: 대기열의 대기시간이 1시간을 초과하여 종료된 전화를 포함/제외
워크플로우로 전화 종료
: IVR 또는 대기열 워크플로우의 통화종료 액션으로 종료된 전화를 포함/제외
서비스 레벨
수신된 전화 중 고객이 연결 대기를 시작한지 N초(목표 시간)내에 응답한 전화의 비율을 뜻해요.
설정 시간: 1초에서 3600초(1시간)까지 설정할 수 있어요. (초기 설정은 20초)
계산 기준
IVR 사용시: IVR종료 후 상담원 연결 시작 시간부터 측정해요.
IVR 종료 액션을 통해 종료되지 않고 도중에 이탈한 콜은 부재중으로 집계하지 않아요.
IVR 미사용시: 인사말 송출 후 상담원 연결 시작 시간부터 측정해요.
*'상담원 연결 시작 시간' 데이터는 엑셀 파일의 firstWaitingStartedAt 값으로 제공됩니다.
응답 속도 준수율
수신된 전화 중 링이 울리기 시작한지 N초(목표 시간)내에 응답한 전화의 비율을 뜻해요.
설정 시간: 1초에서 3600초(1시간)까지 설정할 수 있어요. (초기 설정은 20초)
계산 기준
전화 링이 울린 시간 시간부터 측정해요.
*'링이 울린 시간' 데이터는 엑셀 파일의 firstRingStartedAt 값으로 제공됩니다.
현황
당일 전화 통계 (구 전화 현황)
1일 누적 전화 수발신 현황을 볼 수 있는 대시보드 입니다.
[채널 프로필]에 설정된 시간대 기준으로 매일 00시에 리셋 됩니다.
집계 수치는 1분마다 업데이트 됩니다.
카드별 의미
수신 응답률
:
총 인입된 전화(수신 콜 + 부재중 콜) 중, 고객과 상담원이 연결된 전화의 비율입니다. 1일 전 동일한 시간대의 응답율과 비교한 값이 보입니다.
(=[수신 전화 중 연결된 통화 수] / [총 수신 전화 수] * 100)
발신 응답률
: 상담원이 고객에게 전화를 걸었을 때 연결된 전화의 비율입니다. 1일전 동일한 시간대의 응답율과 비교한 값이 보여집니다.
(=[발신 전화 중 연결된 통화 수] / [총 발신 전화 수] * 100)
총 인입 전화
: 오늘 총 인입된 전화의 수로, 응답 전화와 부재중 전화의 합산입니다.
응답 전화
: 총 인입 전화 중, 고객과 상담원이 연결된 전화의 수 입니다.
발신 전화
: 상담원이 고객에게 전화를 건 수입니다.
부재중 전화
: 총 인입 전화 중, 연결되지 않고 끊어진 전화의 수 입니다.
서비스 레벨:
총 인입된 전화(수신 콜 + 부재중 콜) 중, 고객의 연결 대기 시간이 목표 시간 이내인 응답 전화의 비율입니다.
응답 속도 준수율:
총 인입된 전화(수신 콜 + 부재중 콜) 중, 링 울린 시간이 목표 시간 이내인 응답 전화의 비율입니다.
수신된 전화 중 종료되지 않은 전화는 집계되지 않으며, 종료된 후에 '응답 전화' 또는 '부재중 전화'로 집계됩니다.
계산 공식
서비스 레벨
= [고객이 연결 대기한 시점부터 N초 내 응답한 수신 콜 수] / [수신 콜 수 + 부재중 콜 수]
예시)
목표 시간 내 응답한 수신 콜 수: 80건
수신 콜 수: 90건
부재중 콜 수: 10건
수신 응답률: 90% = 90/(90+10)
서비스 레벨: 80% = 80/(90+10)
응답 속도 준수율
= [링이 울린 시점부터 N초 내 응답한 수신 콜 수] / [수신 콜 수 + 부재중 콜 수]
예시)
목표 시간 내 응답한 수신 콜 수: 85건
수신 콜 수: 90건
부재중 콜 수: 10건
수신 응답률: 90% = 90/(90+10)
서비스 레벨: 85% = 85/(90+10)
26년 1월 16일부터 새로운 기준의 서비스 레벨이 제공됩니다.
새로운 기준의 서비스 레벨은 26년 1월 1일 이후 데이터부터 제공됩니다.
26년 1월 1일 이전 날짜가 포함된 기간 조회 시 서비스 레벨 지표가 제공되지 않습니다.
기존에 제공되었던 서비스 레벨은 "응답 속도 준수율"로 명칭으로 변경됩니다.

시간 단위는 아래와 같은 규칙으로 표기됩니다

24시간 이상 ~ 744시간(31일) 미만 → N일 N시간
31일 이상 ~ 365일 미만 → N개월 N일
365일 이상: N년
처리 시간 옆 비교 정보(⬆︎/⬇︎)는 설정한 기간과 동일한 직전 기간 대비 변화 수치를 보여 줍니다. 직전 기간과 변화가 없다면 0, 직전 기간 데이터가 없다면 - 로 표기됩니다.

## FAQs

### 전화 모니터링 탭에서 전화 상담을 태그 별로 모아서 볼 수도 있나요?

아니요. 아직 태그별 대시보드는 제공되지 않아요.
[상담 통계]탭에서 [연동 서비스_전화]로 필터를 걸어 태그별 유입량을 조회하실 수 있고, 상담 데이터 다운로드 후 [UserChat data] 시트의 tags 항목과 [UserChat meet data] 시트를 비교하여 간접적으로 확인해보실 수 있어요.

### 전화 모니터링 탭에서 엑셀로 다운 받은 데이터로 직접 계산한 평균 통화 시간과 모니터링 대시보드에 나온 평균 통화 시간이 서로 달라요

엑셀 파일의 시간 데이터는 실제 데이터에서 초 미만 단위를 버림하여 제공하고, 대시보드 평균 시간은 실제 데이터를 평균낸 후 초 미만 단위를 버림하여 제공합니다.
따라서 엑셀로 직접 계산할 경우 최대 1초의 편차가 발생할 수 있으며, 대시보드의 값보다 항상 작거나 같습니다.
- 예시) 실제 통화시간 : 1분 1.5초, 2분 1.9초, 2분 3.2초 인 경우
  엑셀 데이터 통화시간 : 1분 1초, 2분 1초, 2분 3초 로 제공 → 평균 계산 시 1분 41.6초
  대시보드 평균 통화시간 : 1분 42.2초 → 1분 42초로 제공

### 전화 통계에서 평균 후처리 시간을 전화번호 별로 필터링해서 볼 수도 있나요?

평균 후처리 시간은 전화 상담을 진행한 매니저의 오퍼레이터 상태값 중 "전화 후처리 중" 시간을 토대로 계산하므로, 전화번호로 구분되지 않습니다.
오퍼레이터 상태란?(바로가기)

### 엑셀로 직접 계산한 '서비스 레벨' 지표가 대시보드에 표기된 수치와 맞지 않아요.

엑셀과 대시보드 수치가 다른 이유는 '밀리초(ms) 처리 로직' 때문입니다. 서버는 밀리초 단위까지 정밀 계산 후 소수점을 버리지만, 엑셀은 초 단위 미만이 생략되어 오차가 발생할 수 있습니다.

💡 예시 (기준 20초)
- 서버: 시작(09.6초), 연결(30.1초) → 차이 20.5초 → 20초 판정 (준수)
- 엑셀: 시작(09초), 연결(30초) → 차이 21초 계산 (미준수)

firstWaitingStartedAt, engagedAt, firstRingStartedAt 등 주요 지표는 서버에 밀리초 단위로 기록됩니다. 정확한 분석을 위해 대시보드 수치를 최종 지표로 참고해 주세요. 직접 계산 시에는 위와 같은 로직 차이가 발생할 수 있음을 유의 바랍니다.
