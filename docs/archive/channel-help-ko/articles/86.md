## FAQs

### 인스타그램 연동했는데, 고객에게 메시지가 전송되지 않아요

인스타그램 메시지의 경우 약 350글자(1,000byte)를 넘어가면 인스타그램 정책에 의하여 메시지 전송에 실패하게 됩니다. 
메시지 내용이 길어 전송에 실패한 경우, 메시지 텍스트를 나누어 전송해 주세요.

### 인스타그램 연동 시, 채널톡에 연동되는 정보가 궁금해요

- 대화를 시작한 고객의 인스타그램 아이디, 이름, 프로필 이미지 정보가 채널톡에서 표시됩니다.
- 만약 고객이 인스타그램에 이름 및 프로필을 설정하지 않으신 경우 채널톡에서는 익명으로 표시됩니다.
- 이미 채널톡 고객DB에 저장된 회원이라면 통합해줄 수 있습니다. (→ 방법 확인하기)

### 인스타그램 연동시, 이미지를 전송할 수 있나요?

채널톡에서 인스타그램 메신저로 사진 전송이 가능합니다. 

단, 아래 경우 이미지가 아니라 링크 형식으로 전송되는 점 참고해주세요.  
- 파일이 8MB를 넘는 경우
- heif, heic 확장자인 이미지인 
- 이미지가 아닌 첨부파일의 경우

### 인스타그램 스토리에 답장이 달렸다는 메시지가 와서 클릭했는데 볼 수가 없어요

인스타그램 스토리가 유지되는 24시간이 지나면 해당 링크를 클릭해도 접속할 수 없습니다.

### 인스타그램 메신저에서 고객에게 답변했더니 채널톡에서는 봇 답변으로 표시돼요.

인스타그램 메신저에서 직접 답변을 한 경우, 채널톡에서 진행중인 상담에는 봇이 답변을 했다고 표시됩니다.

### 인스타그램 연동 후, 수신함에서 고객에게 메시지를 보냈는데 상담이 종료되었어요

고객이 메시지를 보낸 지 7일이 지나면 인스타그램에서 상담 세션이 자동으로 종료됩니다. 따라서 채널톡 수신함에서 해당 상담에 답변을 보내면, 세션 종료로 인해 메시지 전송이 실패합니다.

### 갑자기 인스타그램 연동이 끊겼어요

1.페이스북 비밀번호를 변경하면 연동이 해지됩니다.

2. 인스타그램 메신저를 연동하면 60일마다 재인증이 필요합니다.
- 재인증하지 않고 60일이 지나면 연동이 끊겨, 인스타그램에서 보낸 메시지가 채널톡으로 전송되지 않습니다.
- 연동 만료 7일 전, 해당 채널의 모든 소유자에게 채널봇이 ‘나와의 대화방’을 통해 재인증 안내를 보내드립니다.
- 또한, 페이스북 시스템상의 이유로 예고 없이 연동이 변경되거나 조기 만료되어 재인증이 필요할 수 있습니다.

3. 기존 연동 정보를 유지하려면 최초 연동 시 로그인했던 계정으로 재인증을 진행해 주세요.
- [채널 설정] → [연동] → [인스타그램 메신저] → [재인증 필요] 클릭
- 이후 새 창에서 페이스북 로그인 후 재인증을 완료하면 됩니다.
