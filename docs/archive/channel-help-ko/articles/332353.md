# 지식

Source: https://docs.channel.io/help/ko/articles/%EC%A7%80%EC%8B%9D-803f6ac9

지식이란 고객 ALF가 참조할 수 있는 모든 자료(문서, 파일 등) 를 모아 관리하는 공간입니다.

## Body

지식이란?
지식은 고객 ALF가 참조할 수 있도록 문서, 파일, 웹사이트 등 다양한 자료를 모아 관리하는 공간입니다.
아티클과 FAQ뿐만 아니라 엑셀, PDF 파일도 지식으로 등록할 수 있어, 도큐먼트에 직접 작성하지 않아도 필요한 정보를 쉽게 추가할 수 있습니다.
각 지식마다 필터링 조건을 설정할 수 있어, 고객 ALF가 상황에 따라 어떤 자료를 참고할지 섬세하게 제어할 수 있습니다.
RAG
RAG(검색 기반 생성)는 Retrieval-Augmented Generation의 약자로, AI가 답을 만들기 전에 필요한 정보를 내부 지식에서 먼저 찾아보고, 그 내용을 바탕으로 답변을 생성하는 기술입니다.
지식이 잘 정리되어 있을수록 RAG 품질이 향상되며, 구체적이고 구조화된 지식을 추가할수록 ALF는 더욱 정확하고 신뢰도 높은 답변을 제공합니다.
지식 구조
더 잘 활용할 수 있도록 지식의 구조를 소개해 드릴게요. 지식 센터는
폴더
와
지식 항목

폴더
목적이나 주제별로 폴더를 여러 개 생성하여 지식 항목을 묶어 관리할 수 있는 단위입니다.
각 폴더에는 참조 설명을 작성하거나, 필터링 조건을 설정하여 상황별로 다른 지식을 참조하도록 제어할 수 있습니다.
지식 항목
폴더 안의 실제 참고할 자료를 의미하며, 아티클, 엑셀 등 다양한 형식으로 등록할 수 있습니다.
각 지식 항목은 개별적으로 참조 여부 설정이 가능하고, 필요시 특정 항목만 활용할 수도 있습니다.
폴더
폴더를 새롭게 생성하고 관리하는 방법 자세히 알려 드릴게요. 폴더는 지식 탭에서 생성할 수 있고, 폴더별로 고객 ALF가 참조할 필터링 조건과 동작할 서비스 등을 세부적으로 설정할 수 있습니다.
최상위 폴더는 고객 ALF가 항상 참고하는 기본 폴더로, 참조 설명이나 필터링 조건을 설정할 수 없습니다. 하위 폴더부터는 참조 설명과 필터링 조건을 설정할 수 있습니다.

하위 폴더는 상위 폴더의 설정을 따르며, 상위 폴더 설정 조건과 하위 폴더의 설정 조건을 일치하는 경우만 하위 폴더의 지식이 참조됩니다.

동작할 서비스

도큐먼트
도큐먼트 탭에서 스페이스를 만들면 자동으로 지식 센터에도 추가됩니다.
스페이스 안의 아티클 · FAQ는 공개(퍼블리시)된 것만 지식 센터에 올라가며, 고객 ALF도 이 공개된 내용을 참고해 답변을 생성합니다.
콘텐츠 정보의 참조 횟수는 아티클의 참조 횟수가 아닌 스페이스의 참조 횟수를 의미합니다
.
아티클 작성 · 수정은 도큐먼트 탭에서만 가능하고, 지식 센터에서는 등록된 아티클과 FAQ를 읽기 전용으로 확인할 수 있습니다.
ALF 참조 설정
ALF 참조 설정은 스페이스 단위로만 설정이 가능합니다.
스페이스 ALF 참조 ON: 스페이스 내 공개 상태 아티클·FAQ 참조
스페이스 ALF 참조 OFF: 스페이스 내 모든 아티클·FAQ 미참조
모든 언어 참조 설정
우측 상단의 점 세개 메뉴에서 모든 언어 참조 설정이 가능합니다.
모든 언어 참조 설정 ON: 도큐먼트에 번역본이 없어도, ALF가 고객의 문의 언어를 자동으로 인식해 답변할 수 있어요
모든 언어 참조 설정 OFF: 도큐먼트에 해당 언어로 번역된 버전이 있을 때만 참조하여 답변합니다.

웹사이트
웹사이트 URL을 등록하면, 운영 중인 웹사이트의 페이지 정보를 크롤링하여 ALF가 지식으로 활용할 수 있습니다. 자사 홈페이지, 외부 가이드, 정책 페이지 등 웹에서 열람 가능한 URL이라면 그대로 ALF의 지식이 됩니다.
웹사이트 추가하기
[AI → 설정 → 지식 → 지식 추가]에서 웹사이트를 선택합니다.
웹사이트 URL과 이름(선택)을 입력합니다.
URL을 입력하면 해당 URL의 하위 페이지까지 자동 검색됩니다.
최대 3개의 웹사이트 URL을 등록할 수 있습니다.
URL을 입력하면 최대 3,000개의 하위 페이지를 추출할 수 있습니다.
웹사이트 크롤링 동작 시간은 최대 12시간입니다. 12시간이 초과되면 실패합니다.
필요한 경우 고급 설정을 통해 수집 범위를 조정할 수 있습니다.
웹페이지 수집 상태를 확인합니다.
페이지 수가 많을수록 변환 시간이 오래 걸릴 수 있습니다.
웹페이지 수집 상태가 '완료'일 때 ALF가 참조하여 답변합니다.
웹페이지가 ‘완료’ 상태가 되면 ALF가 해당 페이지를 참조해 답변합니다.
필요하지 않은 페이지는 ‘ALF 참조’ 옵션을 끄면 제외할 수 있습니다.
웹사이트 다시 가져오기
웹사이트 정보는 등록 시점의 내용만 반영되며,
변경된 내용은 자동으로 업데이트되지 않습니다
. 내용이 변경되었다면 '다시 가져오기’를 통해 새로 반영해 주세요.
지식 목록에서 해당 웹사이트의 더보기(...) → 다시 가져오기를 실행할 수 있습니다.
다시 가져오기는 2시간에 1회 실행 가능하며, 완료까지 시간이 소요될 수 있습니다.
등록 실패 시 확인 사항
웹페이지 등록은 크롤링이 가능한 공개 웹사이트를 기준으로 지원하고 있습니다.사이트 구조나 접근 조건에 따라, 일부 웹페이지는 정상적으로 가져오지 못할 수 있습니다.
아래와 같은 경우에는 웹사이트 등록이 실패할 수 있습니다.
접근 제한이 있는 페이지
로그인이나 인증이 필요하거나, 보안 설정 또는 국가별 접속 제한이 적용된 경우
자동 크롤링이 어려운 페이지 구조
페이지 구조가 비표준이거나 자동 수집이 어려운 형태(노션 퍼블리시 링크, div 기반 링크 등)
페이지 규모 또는 로딩 방식으로 인한 제한
페이지 수가 매우 많거나(대용량 쇼핑몰 등), 하단으로 내려갈 때 계속 로딩되는 무한 스크롤 구조
일시적인 네트워크 또는 수집 오류
문제를 확인한 후 다시 가져오기로 한 번 더 시도해 주세요.반복해서 실패한다면, 도큐먼트나 PDF 업로드 등 다른 방식으로 등록하는 것을 권장합니다.
고급 설정
고급 설정을 통해 수집 대상을 직접 제어할 수 있습니다. 일반적으로는 기본 설정만으로도 웹사이트 정보가 정상적으로 수집되며, 자동 수집에 문제가 있거나 특정 페이지를 제외, 추가해야 하는 경우에만 고급 설정을 사용해 주세요.
추가 URL:
자동 수집되지 않은 페이지를 직접 지정해 추가할 수 있습니다.
제외 URL:
ALF가 참조하지 않아야 할 내부용, 테스트 페이지 등을 제외 URL로 지정할 수 있습니다.
페이지 요소 지정:
웹페이지 안에서도 ALF가 참조할 정보와 제외할 정보를 더 세밀하게 설정할 수 있습니다. 페이지 요소 지정은 웹페이지 구조(CSS)에 대한 이해가 필요한 고급 설정으로 특정 요소가 잘못 수집되거나 누락되는 경우에만 사용하는 것을 권장합니다. (→ 더 알아보기(최하단))
비슷한 페이지를 묶어서 추가 또는 제외하기
주소 형식이 비슷한 페이지가 여러 개인 경우, 달라지는 부분에 별표(**)를 사용하면 해당 경로의 페이지를 한 번에 수집 또는 제외할 수 있습니다.
예시: https://example.com/notice/**
결과: notice 아래의 모든 공지사항 게시글 수집 또는 제외(예:
/notice/1
,
/notice/2
,
/notice/new
등)
엑셀
엑셀 파일 업로드
업로드할 때는 반드시 ‘참조 설명’을 입력해야 등록이 가능합니다.
업로드가 완료되면 지식 센터 내에서 읽기 전용 미리보기 형태로 생성되며, 필요한 경우 소속될 폴더를 선택할 수 있습니다.
파일 내에 여러 시트(sheet)가 포함되어 있으면 시트 별로 각각 내용 확인이 가능합니다.
엑셀 시트 참조 시, 고객 문의 내용과 가장 적합한 참조 설명을 가진 하나의 시트만 참조합니다.
ALF는 한 번의 답변에서 하나의 시트만 참조합니다. 여러 엑셀 파일이나 한 파일 내 여러 시트를 동시에 참조하는 것은 현재 지원되지 않습니다.
참조 설정
ALF 참조 : 각 엑셀 파일 별로 ALF 참조 여부를 On/Off 할 수 있습니다.
참조 설명 : ALF가 어떤 상황에서 파일을 참조해야 하는지 참조 설명을
반드시 입력해 주세요.
참조 설명이 없는 엑셀 파일은 ALF 답변 시 참조하지 않습니다.
또한 파일 내에 여러 시트가 있는 경우, 상황에 따라 특정 시트를 참조하도록 설명을 구체적으로 작성해 주세요.
작성 예시)
상품별 재고 확인 시 {상품 코드별 재고수량} 시트 참조
환율 계산이 필요할 때 {환율정보} 시트 참조
엑셀 작성 시 유의 사항
파일 크기는 10MB 이하만 첨부할 수 있습니다.
한 시트에는 반드시 하나의 표(테이블)만 있어야 합니다.
테이블의 첫 행은 반드시 헤더(칼럼 명)로 구성되어야 ALF가 정확하게 인식할 수 있습니다.
테이블의 맨 왼쪽 위(A1 칸)부터 빈칸 없이 데이터가 있어야 엑셀 업로드가 가능합니다.
상품 가격 등 수치형의 의미를 가져야 하는 경우, 숫자로 업로드 되어야 인식됩니다.
현재는 엑셀 파일만 지원하며,
구글 스프레드시트 연동
은 추후 제공 예정입니다.
PDF
PDF 파일 업로드
10MB 이하의 PDF 파일을 업로드할 수 있습니다.
최대 100개까지 업로드할 수 있습니다.
PDF 내 이미지, 표, 레이아웃 등은 인식되지 않고, 텍스트 콘텐츠만 ALF가 참조할 수 있습니다. 텍스트 외 이미지 인식 등은 향후 업데이트에서 지원될 예정입니다.
참조 설정
ALF 참조 : 각 PDF 파일 별로 ALF 참조 여부를 On/Off 할 수 있습니다.

폴더 내부에 폴더 및 지식이 포함되지 않은 빈 폴더만 삭제할 수 있습니다. 삭제 후 복구는 가능하지 않습니다.
지식:
우측 점 세 개(⋮)를 눌러 [옮기기], [링크 복사], [삭제]를 할 수 있습니다.
도큐먼트를 제외한 지식 항목(예: 엑셀, PDF)만 삭제할 수 있습니다. 삭제 후 복구는 가능하지 않습니다.
하위 폴더 삭제
하위 폴더를 삭제할 때 해당 폴더에 도큐먼트가 지식으로 포함되어 있으면 하위 폴더는 그대로 삭제되고 그 안의 도큐먼트는 자동으로 상위 폴더로 이동됩니다.
지식 필터링하기
ALF  참조 상태(켜짐, 꺼짐)따라 지식을 필터링할 수 있습니다. 다른 페이지를 보고 다시 돌아오더라도 필터링은 계속 유지돼요.
지식 또는 폴더의 제목으로 검색할 수 있습니다.
자주 묻는 질문
페이지 요소 지정 설정에 대해 자세히 알고 싶어요
제외할 페이지 요소:
ALF가 참조하지 않아야 할 영역을 수집 대상에서 제외합니다.광고 영역이나 내부 전용 안내처럼 답변에 불필요한 정보를 숨길 수 있습니다.
예시:
.advertisement-section
클릭 동작이 필요한 페이지 요소:
탭, 드롭다운, 아코디언처럼 클릭해야 펼쳐지는 UI는 자동으로 수집되지 않을 수 있습니다. 이 경우 해당 요소들을 CSS 셀렉터로 명시하면, 자동으로 클릭해서 펼친 상태로 가져옵니다.
예시:
.accordion
.tab-content
로딩 대기 요소:
페이지 내 일부 영역의 로딩이 느려 내용이 누락되는 경우, 해당 요소들을 CSS 셀렉터로 명시하면 그 요소들이 화면에 나타날 때까지 기다렸다가 웹페이지 정보를 가져옵니다.
예시:
.lazy-element
#main-hero-image
CSS 셀렉터 작성 방법
페이지 요소 지정은 웹페이지 구조에 따라 설정 방식이 달라질 수 있으므로, 적용 후 실제 수집 결과를 반드시 확인하는 것을 권장합니다.
입력값은 유효한 CSS 셀렉터여야 하며, document.querySelector() 함수에서 인식 가능한 형태만 사용할 수 있습니다.
여러 클래스를 띄어쓰기 없이 이어서 입력하면 AND 조건으로 동작합니다.
예시:
.spreadPanel.header.title
은
spreadPanel
header
title
세 클래스를 모두 가지는 요소를 선택합니다.
CSS 셀렉터를 사이에 콤마(,)를 사용하면 OR 조건을 나타낼 수 있습니다.
예시:
.title
,
.description
은
title
또는
description
클래스를 가진 요소 선택합니다.
아티클, FAQ를 공개 또는 비공개 전환하면 ALF가 즉시 반영하나요?
즉시 반영되지는 않습니다. 보통은 수분 내로 처리되지만, 여러 아티클을 한꺼번에 변경하는 경우에는 더 오래 걸릴 수도 있습니다.
지식에 등록된 모든 지식을 팀 ALF도 참조하나요?
아니요, 팀 ALF는 도큐먼트만 참조할 수 있습니다. 웹사이트, 엑셀, PDF는 고객 ALF만 참조할 수 있어요.
지식 외에 ALF가 참조할 수 있는 정보가 있나요?
ALF는 지식외에도 고객 프로필 정보와 상담 프로필 정보를 함께 참조하여 답변에 활용할 수 있습니다.
단, 고객 설명, 고객 태그, 상담 설명, 상담 태그는 ALF의 답변 생성 시 참조 대상에 포함되지 않습니다.

## FAQs

### 지식에 jason 파일을 업로드해서 ALF가 참조하게 할 수 있나요?

아쉽게도 json 파일 형태로 업로드하는 기능은 제공하고 있지 않습니다.

현재 지식은 웹사이트, PDF, 엑셀 파일, 도큐먼트를 통해서 등록이 가능합니다.
