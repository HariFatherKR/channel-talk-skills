# 아티클 알아보기

아티클은 작성자가 작성한 글로 하나의 문서 단위에요. 아티클의 기본 구성에 대해서 알려드려요.

## Body

아티클의 기본 개념
아티클은 작성자가 작성한 글로 하나의 문서 단위입니다.
아티클 상태 구분
공개
퍼블리시된 아티클이며 웹사이트 및 해당 아티클이 속한 카테고리가 공개 상태인 경우 웹사이트에 노출돼요.
아티클 공개 후에도 계속 수정 가능하며, 수정한 버전을 웹사이트에 반영하고 싶다면 반드시 업데이트 버튼을 통해 퍼블리시 해주셔야 적용됩니다.
비공개
현재 웹사이트에 공개되어 있지 않은 아티클을 의미합니다.
