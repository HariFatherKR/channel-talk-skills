# 스페이스 설정하기

Source: https://docs.channel.io/help/ko/articles/%EC%8A%A4%ED%8E%98%EC%9D%B4%EC%8A%A4-%EC%84%A4%EC%A0%95%ED%95%98%EA%B8%B0-8c81b1ba

스페이스 및 웹사이트와 관련된 설정들은 어떤 것들이 있는지 알려드릴게요.

## Body

일반 설정
기본정보
로고: 브랜드 로고를 설정해 주세요. 스페이스 생성 시 자동으로 채널 프로필 이미지를 불러오며 언제든지 수정할 수 있어요. 설정한 로고는 스페이스 리스트 표시, 웹사이트 파비콘 등으로 사용돼요.
스페이스명: 스페이스 리스트 및 웹사이트 헤더에 표시돼요.
언어: 언어를 추가하거나 변경할 경우 아티클, 카테고리 이름 등 스페이스 전반에 반영돼요.
기본 URL:
스페이스를 웹사이트로 퍼블리시할 경우 사용하게 되는 기본 URL이에요
웹사이트 퍼블리시
웹사이트 공개: ON으로 설정하면 고객이 지정된 URL을 통해 웹사이트에 접근할 수 있어요. 아티클은 공개 상태이더라도 웹사이트 퍼블리시 상태가 OFF라면 고객이 아티클에 접근할 수 없어요.
팀 ALF 사용
내부용 AI(팀 ALF)가 스페이스의 공개 아티클을 참조할지 설정할 수 있어요.
참조 여부: ON으로 설정하면 팀 ALF 이용 시 스페이스 내 공개 아티클과 FAQ를 참조하여 답변해요. (
→ 팀 ALF 알아보기
)
SEO
웹에서 검색 가능
옵션을 통해 스페이스의 웹사이트 검색 결과 노출 여부를 선택할 수 있어요.
옵션을 설정하고 난 후 즉시 반영되는 것은 아니며,  검색 엔진에 반영되기까지 기간이 필요합니다.
예) 옵션을 켜놨다가 비활성화로 변경해도, 구글 검색 엔진 업데이트 주기에 따라 일정 기간 검색이 가능할 수 있습니다.
Q.
어떨 때 이 옵션을 OFF 상태로 사용하나요?
A.
어느 곳에도 노출하지 않고 링크를 통해서만 전달하고자하는 내용들은 검색 옵션을 끈 스페이스에서 관리할 수 있습니다.
OG 태그
웹사이트의 OG 태그를 설정해요. (웹사이트가 공유될 때 보여지는 이미지, 제목, 설명을 설정해요.) 설정하지 않은 경우 스페이스명과 로고로 구성된 기본 이미지가 자동으로 생성되어 보여요.
이미지 확장자는 jpg, jpeg, png를 지원합니다.
이미지 비율은 1.91:1로 등록해 주세요. (1,200x630px 권장)
작성자 프로필
웹사이트 내에서 아티클 작성자로 표시되는 프로필을 설정해요. 스페이스 생성 시 채널의 팀 멤버 프로필로 자동으로 입력되며 수정이 가능해요.
작성자 프로필은 스페이스별로 다르게 설정할 수 있어요.
커스텀 도메인
사용 중인 자사 서비스의 도메인을 등록하여 도큐먼트에 접속할 수 있습니다.
커스텀 도메인
스페이스를 웹사이트 퍼블리시할 경우 원하는 주소로 설정할 수 있어요.
구입한 도메인만 커스텀 도메인으로 설정할 수 있어요.
도메인 CNAME DNS 레코드 등록하기
채널톡에서 커스텀 도메인 설정 전, 도메인 구매처에서 CNAME DNS 레코드를 등록해야합니다.
레코드 등록 값을 확인하여, 도메인 구매처에서 등록해주세요.
레코드 타입:
CNAME
(”canonical name”)
레코드명:
사용할 커스텀 도메인 주소
값:
cname.docs.channel.io
TTL:
300
(초)
자세한 등록 방법은 각 도메인 구매처마다 다르기에, 구매처에서 확인해주세요.
카페24 DNS 연동 가이드
후이즈 DNB 연동 가이드
가비아 DNS 연동 가이드
그 외의 서비스
레코드 설정 화면에서 CNAME 레코드, Host / Name, Value 값 붙여넣기를 진행해주세요
채널톡에서 커스텀 도메인 입력하여 설정하기
https:// 를 제외한 도메인을 입력해주세요.
등록 후 약 5분 후에 연동이 완료됩니다.
(30분 이상 연결이 지연되는 경우 채널팀으로 문의해 주세요.)
유효한 도메인이 아닐 경우, 등록이 불가합니다.
도메인 검증 에러 발생 시 확인사항
도메인 설정 과정에서 도메인 검증 오류가 발생하는 경우, 아래 항목을 점검해 주세요.
CNAME DNS 레코드 등록 확인: 도메인 구매처에서 CNAME DNS 레코드가 정상적으로 등록 되었는지 점검 부탁드려요.
CAA 레코드 설정 확인: 해당 도메인 또는 상위 도메인의 CAA 레코드를 점검해 주세요. 만약 이미 다른 값이 설정되어 있다면, 기존 값과 함께
0 issue "letsencrypt.org"
항목을 추가해 주세요.
리디렉션 관리
사용하시던 문서가 있다면 해당 URL을 도큐먼트에서 만든 문서에 연결할 수 있어요.
리디렉션을 이용하는 경우 커스텀 도메인 등록이 필수입니다.
스페이스 삭제
스페이스를 삭제하는 경우 스페이스 내 아티클도 영구적으로 삭제되며 삭제된 데이터는 복구할 수 없으니 유의해 주세요.
스타일링 설정
홈페이지 구성
커버이미지: 웹사이트 헤더에 보이는 이미지이며, 고객이 사용하는 디바이스에 따라 리사이징돼요. 최소 1,200x270px 사이즈의 이미지를 업로드해 주셔야 하며, jpg, jpeg, png 파일만 지원해요.
타이틀: 웹사이트 상단에 표시되는 문구를 설정할 수 있어요.
대표 콘텐츠 타이틀: 타이틀 영역 하단에 고정할 대표 콘텐츠를 고르고 원하는 문구를 설정할 수 있어요.
공통
테마 색상: 버튼, 텍스트 등에 쓰일 테마 색상을 지정해요. 최초 생성 시 채널의 테마 색상을 불러오며 언제든지 수정할 수 있어요.
헤더 버튼 문구/헤더 버튼 링크: 웹사이트 우측 상단에 버튼을 만들고 싶다면 문구와 링크를 입력해주세요. 버튼은 1개까지 지원됩니다.
아티클 발행 날짜 및 작성자 표시: 아티클 발행 날짜(아티클을 공개 상태로 변경한 날짜)와 작성자를 표시할지 여부를 설정할 수 있어요.
연동 설정
API 인증 키 관리
OpenAPI를 이용해 운영하시는 웹사이트에 도큐먼트 스페이스, 아티클을 삽입하여 보여줄 수 있습니다.
내부 개발팀을 통한 개발 작업이 필요합니다. 자세한 방법은
개발자 문서
를 참고해주세요.
스페이스 설정 > 연동 > API 인증 키 관리 에서 Open API 사용을 위한 API 인증 키를 발급합니다.
API 인증 키를 활용하여 Open API를 호출합니다.  (→
Open API 호출 개발자 문서 확인하기
)
채널톡 버튼 설치
스크립트 삽입 없이 스페이스에 채널톡 버튼을 쉽게 연동할 수 있습니다. 고객은 스페이스에 포함된 모든 아티클에서 궁금한 점에 대해 바로 채널톡 버튼을 눌러 문의할 수 있습니다.
도큐먼트에서 채널톡 버튼으로 문의한 고객은 모두 익명의 고객으로 인식됩니다.
고객 정보 연동을 위해서는 커스텀 도메인 등록이 필요합니다.
커스텀 도메인 설정이 필요하다면 채널팀에 별도 문의해 주세요.
채널 설정 > 일반 설정 > 버튼 설치 및 설정 에서 Plugin Key를 확인합니다
스페이스 설정 > 연동 > 채널톡 버튼 설치에 Plugin Key를 입력 후 저장합니다.
[플러그인 키 불러오기]를 하는 경우,  기본 버튼의 Plugin Key 값이 자동으로 불러와집니다.
멀티 플러그인 기능을 사용중인 경우, [플러그인 키 불러오기]를 하면 채널의 기본 플러그인이 불러와집니다.
