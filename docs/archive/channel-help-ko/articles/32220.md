CSV 파일을 업로드를 통해 여러 명의 고객 정보를 한 번에 업데이트 가능합니다.

이 때, 회원 고객의 정보를 불러오기할 지, 리드 고객의 정보를 불러오기할 지 선택합니다. (

회원과 리드 구분 없이 혼합해서 한 번에 불러오는 기능은 제공되지 않습니다. 회원이나 리드 중에 반드시 하나를 선택하세요.
주의
채널톡에 검증되지 않은 리드만 있는 상태에서 리드 고객 한번에 불러오기를 하면, 새로운 검증된 리드가 생성되며 MU*가 증가합니다.
고객 한번에 불러오기를 하면, 동일한 연락처를 가진 검증된 리드와 회원이 자동으로 통합됩니다. (
유니피케이션
).
회원 업로드할 경우 → 리드를 찾아서 회원에 유니파이합니다.
리드 업로드할 경우 → 회원을 찾아서 회원에 유니파이합니다.
부트*된 적이 없는 리드는 즉시 유니피케이션됩니다.
부트된 적이 있는 리드는 유니피케이션이 지연됩니다. 해당 리드가 사이트에 접속하여 로그인하면 새롭게 생성된 회원 고객과 통합됩니다.
유니피케이션이 지연될 경우, 통합이 완료될 때까지 일시적으로 MU가 증가할 수 있습니다.
각주
MU(Managed User)란? MU(Managed User)는 고객 연락처에 저장되는 전체 고객의 수를 의미합니다. 채널톡 메뉴 내 [고객 연락처 > 전체]에서 확인할 수 있는 숫자에요.
여기서
비용 관련한 자세한 내용을 확인하실 수 있어요.
*부트(Boot)란? 고객이 채널톡이 설치된 웹사이트나 앱에 방문 및 새로고침을 통해 고객 정보가 채널톡에 연동되는 과정을 의미합니다.
2. 업로드 대상 선택
①
회원 불러오기
'템플릿 다운로드 (회원)'를 클릭하여 엑셀 형태의 템플릿을 다운받아 내용을 채우고, CSV 파일로 변환합니다.
파일을 업로드하면, 채널톡에서는
'회원 아이디(memberId)'
로 기존 고객을 식별합니다.
동일한 ‘회원 아이디(memberId)’를 가진 기존 고객이 있으면, 해당 고객의 정보를 업데이트합니다.
기존 고객이 없으면 새로운 고객을 생성합니다.
주의
회원 아이디(memberId)를 잘못 입력하면 다른 고객과 정보가 섞여 상담 내용이 유출될 수 있으니, 반드시 정확하게 입력하세요.
값이 없거나 빈칸이면 불러오기에 실패합니다.
임의의 값을 입력하면 불러오기는 되지만 권장하지 않습니다. 회원 정보가 없다면 ‘회원 업로드’ 대신 ‘리드 업로드’를 이용하세요.

휴대폰 번호

'템플릿 다운로드 (이메일 또는 휴대폰 번호)'를 클릭하여 엑셀 형태의 템플릿을 다운받아 내용을 채우고, CSV 파일로 변환합니다.
CSV 파일을 업로드하고, 이메일 또는 휴대폰 번호 중 어떤 것으로 고객 정보를 식별할지 선택합니다.
같은 이메일 또는 휴대폰 번호를 가진 기존 고객이 있으면, 해당 고객의 정보를 업데이트합니다.
기존 고객이 여러 명일 경우, 가장 최근 접속한 고객의 정보를 업데이트합니다.
기존 고객이 없으면 새로운 고객을 생성합니다.
3. 고객 프로필 매핑
CSV 파일 업로드 후, 파일의 열과 채널톡 고객 프로필을 매핑합니다.
기준이 되는 항목이 첫번째 열에 위치합니다. 이후 열에는 팀 멤버가 수정 가능한 항목들이 순서대로 표시됩니다.
수신 거부 필드(unsubscribeEmail, unsubscribeTexting)
기존 고객의 정보를 업데이트 하는 경우 CSV 파일의 수신 거부 값을 다음과 같이 반영합니다.
CSV에 수신 거부 값이 없는 경우: 고객의 기존 값을 유지합니다. (불러오기 설정과 관계없이 동작)
CSV에 수신 거부 값이 있는 경우: 고객의 기존 값은 CSV의 값으로 덮어쓰기 됩니다.
신규 유저를 등록할 때는 모든 수신 거부 항목이 TRUE인지 FALSE인지 명시해야합니다. 예를 들어, 이메일 리드 불러오기 시에도 이메일 수신 거부 및 문자 수신 거부 값이 모두 빈 값이면 안됩니다.
기존 유저 정보를 업데이트할 때는 업로드하는 파일에 수신 거부 열이 없어도 됩니다.
업로드한 행의 개수가 30개를 초과하면, 첫 30개 행만 화면에 보여집니다. (열은 다 보여짐)
굳이 작업하고 싶지 않은 열이 있다면 ‘불러오지 않음’으로 선택할 수 있습니다.
하나의 고객 프로필은 업로드한 항목에 한 번만 사용되어야 합니다.
의도하지 않은 오류가 발생할 경우, 위와 같이 안내해드려요. 그대로 진행할 지 또는 파일을 점검하고 다시 업로드할 지 선택할 수 있습니다.
원하는 고객 프로필이 없다면, 고객 프로필 검색창에서 바로 생성할 수 있습니다.
4. 불러오기 설정
업로드한 파일에 빈 셀이 있는 경우, 기존 데이터에 대한 처리 방식을 선택할 수 있습니다.
기존 데이터 유지
빈 셀은 무시되고, 기존 고객 정보가 그대로 유지됩니다.
기존 데이터 비우기
(수신거부 필드는 제외)
빈 셀은 해당 값을 ‘없음’으로 덮어씌웁니다. 단, 수신거부 필드는 빈 값이라도 기존 값이 유지됩니다.
고객 연락처 및 마케팅 메시지 발송 시, 고객 필터링에 활용할 수 있는 '고객 불러오기 태그'를 생성할 수 있어요.
‘고객 불러오기 태그’에는 업로드한 CSV 파일명이 자동으로 입력되며, 직접 수정 가능합니다.
주의
CSV 파일을 업로드하고 고객 불러오기를 한 후에는
이전 상태로 되돌릴 수 없으니
, 신중하게 진행해주세요.
5. 불러오기 결과 확인
불러오기가 완료되면 소유자와 요청한 팀 멤버에게 봇 메시지로 안내됩니다.
또는 [고객 연락처] 하단에 [고객 불러오기 로그]를 눌러 확인할 수 있어요.
6. 참고 사항
① 실패 항목 다운로드
불러오기에 실패한 항목이 있다면 별도로 엑셀 파일을 다운로드하여 수정 후, CSV로 변환하여 재업로드할 수 있어요.
각 항목 설명:
생성: 새롭게 생성된 고객의 수
업데이트: 기존 고객과 매칭된 고객의 수. 매칭만 되고 실제로 기존 고객의 정보가 변경되지 않았더라도, 업데이트로 인식됨.
실패: 파일에서 불러오기 실패한 행의 수
불러온 고객 수, 생성 수, 업데이트 수는 파일에 같은 고객이 여러 번 등장하더라도 1명으로만 계산됩니다. 즉, 중복된 행을 제거한 실제 고객 수 기준으로 수치가 표시됩니다. (2025년 5월 22일부터 적용)
화면에는 최대 30개 행만 미리보기로 보여집니다.
참고 사항:
실패 로그는 30일 동안 다운받을 수 있어요.

2열에 문제가 있는 열(errorColumns)의 채널톡 프로필 키가 제공됩니다.
3열에 실패 사유(errorReasons)가 제공됩니다.
1행에 매핑된 채널톡 고객 프로필 키가 제공됩니다.
실패한 행들만 제공됩니다.

## FAQs

### 고객 한번에 불러오기할 때, 업로드할 수 있는 CSV 파일 크기 제한이 있나요?

100MB 로 제한됩니다.

### CSV 파일 업로드하려는데, 권한이 없다고 해요. 어떤 권한이 필요한가요?

고객 연락처 수정 권한이 필요합니다.

### 회원과 리드를 구분하지 않고 한 꺼번에 고객 불러오기 가능한가요?

회원과 리드 구분 없이 혼합해서 한 번에 고객을 불러오는 기능은 제공되지 않습니다. 회원이나 리드 중에 반드시 하나를 선택하세요.

### 연락처가 포함된 CSV 파일을 업로드하여 회원 정보를 불러오기 할 수 있나요?

회원 정보를 불러오기하려면, 회원아이디(memberId) 값이 반드시 있어야 합니다.

### 기존 고객의 연락처를 한 번에 수정하려면 어떻게 해야 하나요?

CSV 파일 업로드를 통해 한 번에 고객 불러오기 기능을 이용하시면 됩니다.
- 회원은 memberId를 기준으로 기존 고객 정보를 찾기 때문에 이메일과 휴대폰 번호 모두 수정할 수 있습니다.
- 리드는 이메일 또는 휴대폰 번호 중 하나를 기준으로 찾기 때문에, 기준이 되는 연락처는 수정할 수 없고 다른 연락처만 수정할 수 있습니다.
예시:
- 이메일을 기준으로 찾은 리드 → 이메일 수정 불가 / 휴대폰 번호 수정 가능
- 휴대폰 번호를 기준으로 찾은 리드 → 휴대폰 번호 수정 불가 / 이메일 수정 가능

### 고객 불러오기를 통해 기존 고객 정보를 수정하려 했지만 기존 값이 없어지지 않는 경우가 있어요. 왜 그런가요?

1. 리스트 타입
- 리스트 타입의 고객 프로필은 고객 정보 중에서 여러 값을 가질 수 있는 항목을 의미합니다. 
- 리스트 타입의 고객 프로필은 기존 값에 불러오기한 값을 추가(Append) 하는 방식으로 동작합니다. 
- 예를 들어, 고객이 여러 개의 ‘구매 내역’이나 ‘관심 카테고리’를 가질 수 있는 경우, 이러한 정보는 리스트 타입으로 처리됩니다. 
- 즉, 새로운 값을 추가(Append)하는 방식으로 동작합니다.

2. 그 외 타입
- 그 외 타입의 고객 프로필은 기존 값을 덮어쓰기(Replace) 합니다. 
- 하나의 값만 가질 수 있는 항목들(예: 이름, 휴대폰 번호 등)의 기존 값은 덮어쓰기(Replace)가 됩니다.

### CSV 파일 업로드를 통해, 리드 고객의 이메일과 휴대폰 번호를 동시에 수정할 수 있나요?

- 동시에 수정은 어렵습니다.
- 리드 고객 CSV 파일을 업로드할 때, 고객 식별 기준으로 이메일 또는 휴대폰 번호 중 하나를 선택해야 합니다.
- 선택한 식별 기준은 변경할 수 없으며, 다른 연락처 정보만 수정 가능합니다. 예: 고객 식별 기준으로 ‘이메일’을 선택한 경우, 휴대폰 번호만 수정 가능.

### 업로드한 CSV 파일에 같은 고객이 여러 명 있으면 어떻게 되나요?

같은 고객이 여러 번 등장하면 구분하지 않고 모든 행이 작업됩니다. 
따라서 한 고객은 여러 번 서로 다른 정보로 수정되며, 최종적으로 마지막으로 수정된 프로필 값이 적용됩니다. (파일 내 고객 순서는 보장되지 않습니다.)

### 고객 불러오기 하면 불러오기 날짜 기준으로 어떤 값이 업데이트 되나요?

신규 생성 고객: 
createdAt(최초 접속 시간)과 lastSeenAt(최근 접속 시간)이 찍힙니다.

기존 고객이 업데이트되는 경우:
updatedAt(최근 수정 시간)만 찍힙니다.

### CSV 파일 업로드 시, 고객 정보는 수정하지 않고 마케팅에서 대상 고객 필터링 용도로만 사용할 수 있나요?

가능합니다. 

다운받으신 템플릿에서 1열만 남기고 나머지 열을 삭제한 후, 고객 정보를 한 줄로 입력하면 됩니다. 
이렇게 하면 ‘고객 불러오기 태그’를 활용하여 마케팅에서 대상 고객을 필터링할 수 있습니다.

단, 이 때 새로운 유저가 생성될 경우, 반드시 수신 거부 필드(unsubscribeEmail, unsubscribeTexting) 를 포함해야 합니다.

### 유니피케이션 지연 없이 모든 고객 정보를 즉시 통합할 수 있나요?

- 지연된 유니피케이션에 해당하는 경우, 즉시 통합되지 않습니다.
- 이는 고객이 사이트에 접속해 있는 상태에서 갑작스럽게 정보가 변경될 경우, 채팅 내역이 사라지거나 새로운 대화가 갑자기 나타나는 등의 혼란을 방지하기 위해서입니다.
- 따라서, 해당 리드(또는 멤버)가 다음번에 사이트에 로그인할 때 자연스럽게 정보가 통합됩니다.

### 리드와 리드를 유니파이(고객 정보 통합)하고 싶어요.

현재는 리드와 회원간의 유니파이만 제공하고 있습니다.

### MU 한도 초과로 숨겨진 고객도 고객 불러오기를 하면 숨김이 해제되나요?

MU 한도를 초과해 숨김 처리된 고객이라도, CSV 파일을 업로드해 고객을 한 번에 불러오면 updatedAt(최근 수정 시간)이 변경될 수 있습니다. 

단, lastSeenAt(최근 접속 시간)은 변하지 않기 때문에 숨김 상태는 그대로 유지됩니다.

### CSV 파일로 고객 한 번에 불러오기를 하다가 MU 한도에 도달하면 어떻게 되나요?

고객 불러오기 중 MU 한도에 도달하더라도, 일부 새로운 고객이 생성되거나 기존 고객 정보가 업데이트될 수 있습니다.
단, MU 한도를 초과한 고객은 업데이트되더라도 자동으로 숨김 처리됩니다.
- 예시: MU 한도가 3명이 남은 상황에서, 6명을 신규 업로드하면 3명의 새로운 고객 정보만 보여집니다. 이 때, 어떤 고객이 보일지는 순서가 보장되지 않습니다.

### 고객 불러오기 로그에서 성공한 ‘고객’ 수와 ‘고객 불러오기 태그’로 검색한 결과 수가 달라요.

- MU 수동 한도가 설정된 경우, 고객 불러오기 로그의 ‘고객’ 수와 ‘고객 불러오기 태그’로 검색한 고객 수가 다를 수 있습니다.
- 시간이 지나면서 불러오기 한 고객이 삭제되었거나, MU 한도로 숨겨졌거나, '고객 불러오기 태그'가 30개를 초과해 기존 태그가 삭제된 경우, '고객 불러오기 태그'로 검색되는 고객 수가 달라질 수 있습니다.
- 현재 확인하고 사용할 수 있는 고객 수는 고객 연락처에서 ‘고객 불러오기 태그’로 검색한 결과가 정확합니다.

### 전화 상담만 운영하거나, 사이트에 채널톡 버튼 설치 없이 채팅 링크 제공 방식으로 운영하는 고객사입니다. CSV 업로드로 상담 기록을 통합할 수 있나요?

가능합니다. 다만, 기존 리드들의 연락처를 매니저가 직접 검증해야 합니다.

전화 상담의 경우 자동 검증이 이루어지지만, 
채팅 링크(스탠드 얼론) 제공 방식으로 운영하는 경우에는 수동 검증이 필요합니다.

### 리드 고객 추가를 했는데 "이미 존재합니다"라고 보여요

MU가 설정하신 '수동 한도'에 도달한 경우,
수동 한도 이상으로 저장된 고객은 '최근 접속 시간'이 오래된 고객부터 숨김처리됩니다. 숨김처리된 고객은 저장되어 있지만 숨겨져 있는 상태이기 때문에 고객 연락처에서 조회되지 않고, 마케팅 메시지 발송 대상에서도 제외됩니다.

이미 숨김처리된 고객이라면
동일한 연락처로 리드 고객 추가 시 "이미 존재합니다" 라는 문구가 보이게 됩니다.
