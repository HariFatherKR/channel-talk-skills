## FAQs

### 채널톡과 라인을 연동한 후에도 LINE 챗모드를 사용할 수 있나요?

채널톡과 연동이 되면 LINE Official Account Manager 의 챗모드는 비활성화 돼요. 
이전 상담 데이터는 조회가 어려우며, 챗모드를 활성화하면 연동은 끊어집니다.

### 채널톡에 라인을 연동했는데, 채널톡으로 메시지가 넘어오지 않아요.

아래 2가지 경우인지 확인이 필요합니다:

1. Bot Basic ID로 연동을 했는데 추후에 Premium ID를 가입하셨거나, 아래 항목들 중 기존 정보와 바뀐 부분이 있다면 연동을 끊고 다시 연동을 해주셔야 올바르게 동작합니다.
- LINE Channel ID
- LINE Channel Secret
- Access Secret (long-lived)
- Bot Basic ID (또는 Premium ID)

2. 채널톡과 연동한 LINE Channel을 다른 LINE Channel로 변경할 경우에는 연동을 끊고 다시 연동을 하셔야 정상 동작합니다.

### 라인에서도 담당자별 프로필 아이콘이 노출되나요?

라인과 같은 외부 메신저의 경우, 채널톡에서 설정한 매니저 프로필이 적용되지 않습니다. 채널 프로필로만 응대하실 수 있어요.

### 라인을 채널톡과 연동했는데, 메시지가 보내지지 않아요.

다음의 사항을 확인해 주세요. 
1. 장문 메시지 제한
- 2,000자 이상인 메시지는 전송할 수 없습니다.
2. LINE 무료 메시지 수 제한
- 이용 중인 LINE 플랜에 따라 하루에 전송할 수 있는 무료 메시지 수가 정해져 있습니다. 무료 메시지를 모두 소진한 경우 메시지 전송이 실패하거나, 추가 전송 시 요금이 발생할 수 있습니다.
- 보낸 메시지 수는 매일 오전에 갱신되며, 이로 인해 화면상 잔여 메시지가 남아 있어 보이더라도 실제 전송이 실패할 수 있습니다.

### 라인을 채널톡과 연동했는데, 메시지 유입이 되지 않아요.

라인에는 이용중인 라인 플랜별로 사용할 수 있는 무료 메시지 수가 정해져 있습니다. 
사용 가능한 무료 메시지를 모두 소진했을 시 메시지 전송이 실패하거나, 추가 메시지를 보낼 경우 추가 요금이 발생할 수 있습니다.
다음의 사항을 확인해 주세요. 

보낸 메시지 수는 매일 오전에 갱신되며, 이로 인해 화면상 잔여 메시지가 남아 있어 보이더라도 실제 전송이 실패할 수 있습니다.

### 라인으로 상담을 남겨서 유입된 고객은 이름이 안 보이나요? (랜덤한 이름으로 보이나요)

회원 정보 연동이 되지 않았기 때문이예요. 만약 이미 채널톡 고객DB에 저장된 회원이 맞다면 수동으로 해당 고객의 정보를 통합해줄 수 있습니다. (→ 통합 방법 보러 가기)
