# 채널엑스

Source: https://docs.channel.io/help/ko/articles/%EC%B1%84%EB%84%90%EC%97%91%EC%8A%A4-479e36d6

미지의 취향을 찾아. 쇼핑하는 소셜미디어 채널엑스에서 브랜드 추천부터 상품 구매까지 한 번에 경험해 보세요.

## Body

채널엑스란?
채널톡이 만든 쇼핑과 소셜 미디어가 접목된 플랫폼이에요. 브랜드의 팬들이 직접 작성한 양질의 리뷰 콘텐츠를 확인할 수 있고, 해당 콘텐츠를 통해 상품을 바로 구매할 수 있습니다. (→

)
연동 방법
현재 상품정보 연동은 빌더사 카페24만 지원하고 있습니다. 다른 빌더사에도 연동될 수 있도록 준비하고 있어요.
[채널 설정] - [채널엑스]에서 채널엑스 연동을 ON으로 설정하면, 채널엑스에 자사몰의 상품 정보가 연동됩니다.
채널엑스의 유저가 연동된 자사몰에서 판매하는 상품에 대한 리뷰를 올리게 되면, 채널엑스 앱 내에서 상품 상세 페이지가 보이게 연동되어요. 앱을 이용하는 다른 잠재 고객에게 우리 브랜드를 더 잘 알릴 수 있습니다.
채널엑스 연동은 채널엑스 입점과는 다릅니다. 입점을 통해 채널엑스 앱에서 바로 구매까지 가능하게 하고 싶으시다면, 링크를 통해 입접 신청을 접수해주세요. (→

채널톡 상담 모아보기
빌더사 카페24 여부와 관계없이, 채널엑스 연동을 켜두셨다면 누구나 이용할 수 있습니다.
채널톡 상담 모아보기를 ON으로 설정하면, 자사몰 상담창을 떠난 경우에 발송되는 팔로업 알림 상단에 채널엑스 연동 배너가 뜨게 됩니다.
배너를 통해 고객이 채널엑스 앱을 설치해 상담을 연동하게 되면, 자사몰 채널톡에서 나눈 상담이 채널엑스 앱 내 [마이페이지] - [채팅]에 연동됩니다. 고객은 언제든지 채널엑스 앱에서 상담을 확인할 수 있어요.
고객이 연동하고 나면, 자사몰에서 오프라인 상태일 때 답변하더라도 팔로업 알림 비용이 청구되지 않아요. 채널엑스 앱 연동을 통해 고객과의 대화를 부담 없이 이어가실 수 있습니다.
배송 완료 시 리뷰 모으기
채널엑스를 연동할 수 있는 카페24 빌더사이면서 동시에 유료 플랜을 구독 중일 때만 이용할 수 있습니다.
배송 완료 시 리뷰 모으기를 ON으로 설정하면, 자사몰과 채널엑스로 구매한 상품에 대한 배송 완료 알림톡을 무료로 전송하실 수 있습니다.
알림톡 내 리뷰 작성하기 버튼을 눌렀을 때
고객의 기기에 채널엑스 앱이 설치되어 있다면 → 해당 상품의 정보가 자동으로 포함된 상태의 포스팅 작성 화면으로 연결됩니다.
고객의 기기에 채널엑스 앱이 설치되어 있지 않다면 → 채널엑스 앱 다운로드 화면으로 연결됩니다.
