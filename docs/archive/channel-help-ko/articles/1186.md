# 아티클 작성하기

Source: https://docs.channel.io/help/ko/articles/%EC%95%84%ED%8B%B0%ED%81%B4-%EC%9E%91%EC%84%B1%ED%95%98%EA%B8%B0-be177b0b

아티클은 작성자를 표기할 수 있으며 여러 블록을 조합하여 본문을 구성할 수 있어요. 아티클을 작성하는 방법을 알려드릴게요.

## Body

새 아티클 만드는 방법
아래의 세 가지 경로를 통해 새 아티클을 만들 수 있어요.
[도큐먼트] - [아티클] - 우측 상단 [+아티클 작성하기] 클릭
[도큐먼트] - [아티클]
- 좌측 사이드바 하단 [+모양 아이콘] 클릭
[도큐먼트] - [아티클]
- 좌측 사이드바 내 '카테고리' 우측 [+모양 아이콘] - [새 아티클 작성] 클릭
아티클 작성하기
헤더 구성
제목: 아티클의 제목입니다. 고객에게 노출되는 제목이라 잘 설정해주시면 좋아요.
언어: 아티클의 언어를 선택할 수 있어요. 다른 언어 버전을 선택하여 번역본을 작성할 수 있습니다.웹사이트에 보여질 아티클 작성자를 지정할 수 있어요.
작성자: 현재 작성 중인 작성자들을 확인할 수 있어요.
저장: 입력한 내용이 있을 때마다 자동으로 저장됩니다.
공유
편집 페이지: 편집 중인 페이지의 링크를 확인할 수 있습니다. 팀원들과 공유해보세요.
웹사이트 미리보기: 스페이스가 공개 상태일때만 미리보기 페이지를 확인할 수 있어요.
바로가기: 미리보기 창으로 바로 이동합니다.
링크 복사: 미리보기 창의 링크를 복사합니다.
더보기
페이지 잠금: 다른 사람이 페이지를 공동 수정하지 못하게 잠궈둘 수 있어요.
아티클 복제: 아티클을 복제할 수 있어요.
카테고리 이동: 수정 중인 아티클이 포함된 카테고리를 이동할 수 있어요.
버전 기록: 아티클의 버전을 확인할 수 있어요.
아티클 삭제: 아티클을 삭제할 수 있어요. 삭제된 아티클은 복구되지 않습니다.
공개: 아티클을 퍼블리시하여 노출할 수 있어요. 웹사이트가 '공개' 상태라면 고객이 해당 아티클에 접근할 수 있어요.
만약 이미 공개된 상태의 아티클이라면 [업데이트] 버튼이 보여집니다.
공개 상태의 아티클을 수정하고 난 후에는 꼭 [업데이트]를 눌러서 수정본을 반영해주세요.
SEO 설정: 아티클이 검색 엔진에 잘 노출되도록 설정할 수 있어요.
더보기
를 통해 상세 설정 방법을 알아보세요.
아티클 정보 설정하기
대표 이미지: 대표 이미지를 등록한 경우 대표 이미지가 썸네일로 사용돼요. 대표 이미지를 등록하지 않더라도 아이콘이 포함된 기본 이미지가 보여지며 이는 수정 가능합니다.
기본 이미지 수정
대표 이미지 추가 버튼을 클릭 후 기본으로 설정된 대표 이미지의 배경 색상과 아이콘을 수정할 수 있어요.
색상 및 아이콘 탭에서 배경 색상을 수정해보세요.
아이콘 부분을 클릭하여 아이콘 혹은 이모지를 수정 가능합니다.
대표 이미지 업로드
대표 이미지 추가 버튼을 클릭하여 원하는 이미지를 업로드할 수 있어요.
이미지 크기: 최소 700x366픽셀 이상
지원하는 파일 형식: JPG, JPEG, PNG, GIF 등
이미지 비율: 1.91:1
제목: 아티클을 퍼블리시하기 위해 필수로 입력해 주세요.
소제목: 필요시 입력해 주세요.
아티클 발행 날짜 및 작성자: 아티클 발행 날짜 및 작성자를 아티클에 표시하고 싶지 않다면 [도큐먼트]- [스페이스 설정] - [스타일링] - [공통]에서 '아티클 발행 날짜 및 작성자 표시'를 꺼주세요.

도큐먼트 편집 권한이 있는 팀 멤버들은 문서 동시 편집이 가능해요.

아티클 본문에 FAQ 첨부하기
기존에 작성해 둔 FAQ를 불러오거나 새 FAQ를 만들어 아티클 본문에 추가할 수 있어요. 질문을 클릭하면 답변 내용이 표시됩니다. (→
FAQ란?
)
비공개 상태의 FAQ는 옅은 색으로 표시되며, 고객에게는 노출되지 않습니다.
FAQ 첨부 방법
아티클 본문 하단에 ‘FAQ 추가’ 버튼을 클릭하세요.
FAQ 목록에서 첨부할 FAQ를 선택하세요. (다중 선택 가능)
[저장] 버튼을 클릭하세요.
만약 기존에 작성된 FAQ가 없을 경우, 새로운 FAQ를 바로 생성할 수 있습니다.
아티클 본문 하단에 [FAQ 추가] 클릭 → [+새 FAQ 만들기] 클릭 → 우측 바에서 FAQ를 설정해주세요.
[저장]을 클릭하면 FAQ가 아티클에 첨부됩니다.
[퍼블리시]를 클릭하면 FAQ는 '공개'상태로 변경되며, 고객이 보는 아티클에서 FAQ가 노출됩니다.
FAQ 제목 설정
첨부한 FAQ 목록 상단에 제목을 설정할 수 있어요. 설정한 제목은 스페이스 내 모든 아티클의 FAQ 목록에 적용됩니다.
스페이스 언어에 따라 각 FAQ 제목을 언어별로 설정할 수 있어요.
제목을 숨기려면 입력된 내용을 모두 삭제하세요.
첨부된 FAQ 수정 및 위치 변경
FAQ 수정하기 : FAQ 위에 마우스를 올린 후 편집 아이콘을 클릭하여 내용을 수정하세요.
FAQ 위치 이동하기 : FAQ를 드래그 앤 드롭하여 목록의 순서를 변경할 수 있어요.
첨부된 FAQ 삭제
FAQ 위에 마우스를 올린 후 휴지통 아이콘을 클릭하여 첨부된 FAQ를 삭제할 수 있어요.
FAQ 제목 영역 위에 마우스를 올리면 우측 상단에 ‘FAQ 목록 삭제’ 버튼이 나타납니다. 버튼 클릭시 한번에 목록 전체를 삭제할 수 있어요.
첨부된 FAQ 및 목록을 삭제하면 아티클과의 연결이 해제 됩니다. 등록된 FAQ 원본은 삭제되지 않으니 안심하세요.
SEO 설정하기
작성 중인 아티클의 OG 태그나 슬러그를 설정하여 검색 엔진에 아티클이 더 잘 노출되도록 설정할 수 있어요. SEO 정보는 아티클의 버전별로 관리됩니다.
슬러그란? 웹 사이트의 특정 페이지를 쉽게 읽을 수 있는 형태로 식별하는 URL의 일부입니다.
OG 태그
OG 태그를 설정하여 아티클 링크를 공유할 때 보여지거나 검색 엔진에 더 잘 노출되도록 설정할 수 있어요.
정보를 따로 지정하지 않는 경우 이미지에는 대표 이미지, 타이틀에는 아티클 제목, 설명에는 소제목 또는 본문이 자동으로 표시됩니다.
최소 900x471px 사이즈의 jpg, jpeg, png, gif 파일 업로드가 가능합니다.
클린 URL
아티클의 보여지는 URL을 원하는 링크로 설정할 수 있어요.
아티클 내용에 맞는 키워드로 클린 URL을 설정해보세요.
기본 도메인 - 설정한 커스텀 URL - 고유 ID 형태로 구성됩니다.
고유 ID는 자동으로 부착되며 변경이 불가해요.
URL은 3~30자까지 입력 가능합니다.
알파벳 소문자, 숫자, -, _ 만 입력 가능해요.
클린 URL을 설정하여 사용하다 변경할 경우, SEO에 영향을 주게 됩니다.
아티클 가져오기
기존에 외부 서비스에서 작성·관리하던 문서를 파일 업로드, URL 입력, 또는 다른 스페이스의 아티클 이동을 통해 손쉽게 도큐먼트 아티클로 생성할 수 있습니다.
아티클 가져오기는
유료 플랜 구독
중일 경우에 사용 가능합니다.
우측 상단 [아티클 가져오기] 버튼을 클릭합니다.
파일 / 웹사이트 / 스페이스를 클릭하여 불러오기 방식 중 하나를 선택해주세요.
도큐먼트 수정 권한이 있을 경우 가져오기가 가능합니다. (
→ 역할 및 권한 알아보기
)
파일에서
가져오기
파일을 업로드 하여 하나의 아티클을 만들 수 있습니다.
최대 20개 파일을 업로드하여 가져올 수 있습니다.
업로드 가능한 확장자: pdf, html, txt, csv, md
지원 가능한 파일 용량은 1MB 이하입니다. pdf 파일의 경우 30MB 이하입니다.
UTF-8 형식으로 인코딩 된 파일만 처리할 수 있습니다.
업로드된 파일은 비공개 상태의 아티클로 생성됩니다. 필요한 내용을 수정 후 [퍼블리시]를 눌러 고객에게 노출되도록 설정해주세요.
작성자는 가져오기를 진행한 팀 멤버로 설정됩니다.
시간이 소요될 수 있으며 완료 시 팀챗 [나와의 대화방]으로 알려드려요.
웹사이트에서 가져오기
외부 URL을 통해 가져온 아티클은 비공개 상태의 아티클로 생성됩니다. 필요한 내용을 수정 후 [퍼블리시]를 눌러 고객에게 노출되도록 설정해주세요.
입력한 URL에 하위 페이지가 존재할 경우, 하위 페이지도 가져오는 것을 선택할 수 있어요.
페이지 별 개별 아티클로 생성됩니다.
한 번에 가져올 수 있는 URL은 1000개까지 지원됩니다.
예시) https://channel.io 입력 시, https://channel.io/document, https://channel.io/alf 등 최대 1000개 페이지까지 불러올 수 있음
1MB 이하의 페이지만 가져올 수 있습니다.
페이지가 많을 경우 완료까지 시간이 소요될 수 있으며 완료 시 팀챗 [나와의 대화방]으로 알려드려요.
노션 문서의 경우, 토글 (▶︎) 안에 포함된 내용은 불러 와지지 않아요.
작성자는 가져오기를 진행한 팀 멤버로 설정됩니다.
스페이스에서 가져오기
채널과 무관하게 다른 스페이스의 아티클을 가져올 수 있습니다.

결과를 생성할 스페이스와 복제할 스페이스가 달라야 합니다.
복제할 스페이스에서 지원하는 언어는 결과를 생성할 스페이스에도 전부 포함되어야 합니다.

## FAQs

### 아티클을 이전처럼 새 탭에서 열리게 하려면 어떻게 하나요?

채팅창 안에서 열린 아티클 우측 상단에 '새 탭 열기' 버튼을 클릭하시면 됩니다.

### 내 채널톡 주소에서 아티클 링크를 클릭하면 채팅창 안이 아닌 새 탭에서 열립니다

내 채널톡 주소나 워크플로우 고객용 링크처럼 별도의 링크(스탠드 얼론 링크)를 통해 상담을 진행하는 경우, 마케팅 팝업 메시지 내 도큐먼트 아티클 링크를 클릭하면 채팅창 안이 아니라 새 탭에서 열립니다.
반면, 웹사이트나 앱에 설치된 채널톡 버튼을 눌러 상담을 시작하면 도큐먼트 아티클이 채팅창 안에서 바로 표시됩니다.
