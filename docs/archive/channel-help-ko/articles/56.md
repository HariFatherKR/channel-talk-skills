# FAQ

Source: https://docs.channel.io/help/ko/articles/FAQ-db21218c

고객이 자주 묻는 질문과 답변을 저장해 두면, 고객 ALF가 답변을 이용해 자동으로 대답해 주는 기능이에요.

## Body

영상으로 배우고 싶다면?
FAQ란?
고객이 자주 묻는 답변을 채널톡에 미리 등록해 둘 수 있는 기능이에요. 고객 ALF가 FAQ에 등록된 답변을 기반으로 고객 문의를 해결해 줄 수 있어요. (→
ALF 가이드 보러 가기)
FAQ 생성 방법
도큐먼트에서 FAQ 생성하기
설정 경로 : [도큐먼트] - [FAQ] - 우측 상단 [+ 새 FAQ 만들기]
질문: ALF가 답변 시 출처로 공개되는 문장이며, 최대 100자까지 입력할 수 있어요.
추가 질문: 고객의 다양한 질문 유형에도 매칭될 수 있도록 설정하는 질문입니다. 최대 10개까지 설정할 수 있어요.
답변: 해당 FAQ에 대한 답변만 가능하며, 최대 500자까지 입력할 수 있어요.
저장: 모든 항목을 입력해야 저장 버튼이 활성화됩니다. 저장 시 비공개 상태로 저장됩니다.
저장 후 목록에서 다시 질문을 클릭 → 퍼블리시를 눌러주셔야 ALF가 참고할 수 있는 질문이 됩니다.
유저챗(팀챗)에서 FAQ 생성하기
설정 방법: 답변으로 만들 메시지 위에 마우스 올린 후 'FAQ로 만들기 클릭' 후 등록할 스페이스 선택
선택한 메시지가 FAQ의 답변이 되며 질문은 직접 입력해 주세요.
아티클 작성 화면에서 FAQ 생성하기
설정 방법: 아티클 작성 화면 내에서 답변으로 만들 텍스트를 드래그하여 선택한 상태에서 마우스 올린  후 'FAQ로 만들기' 클릭
선택한 메시지가 FAQ의 답변이 되며 질문은 직접 입력해 주세요.
FAQ 일괄 등록 및 관리
FAQ를 한 번에 다운로드하거나, 업로드하여 신규 FAQ를 등록하거나, 기존 FAQ를 보다 쉽게 수정하고 관리할 수 있어요. 관리 중인 FAQ 목록이 있다면 FAQ 일괄 등록을 통해 지금 바로 FAQ를 시작해 보세요!
FAQ 다운로드
채널에서 관리 중인 FAQ를 전체 혹은 원하는 FAQ만 선택하여 다운로드가 가능합니다.
다운로드 형식은 XLSX 와 JSONL 파일이 지원됩니다.
최대 1만건까지 다운로드가 가능합니다.
답변 데이터 항목을 통해 FAQ의 질문, 답변만 다운로드할지, 목록에서 보여지는 상태, 언어, ALF 사용 정보, FAQ id까지 다운로드할 지 선택할 수 있어요.

FAQ 일괄 업로드

작성된 파일을 드래그 또는 업로드해주시면 일괄 등록됩니다.

## FAQs

### 모든 팀 멤버가 FAQ를 생성 및 수정할 수 있나요?

- 채널에 역할을 별도로 설정하지 않으셨다면, 모든 팀 멤버가 생성 및 수정할 수 있습니다.
- ‘상담 설정’ 권한이 없는 역할의 팀 멤버는 FAQ를 생성 및 수정할 수 없어요.

### FAQ는 최대 몇 개까지 생성할 수 있나요?

생성 개수에 제한은 없습니다.

### 생성한 FAQ는 어떻게 편집하나요?

목록에서 클릭 후 바로 편집해 주시면 됩니다. 질문/답변/언어 중 하나라도 수정 사항이 발생하면 우측 상단에 저장 버튼이 활성화되어요. 편집 후 저장해주시면 됩니다.

### FAQ를 삭제하면 복구할 수 있나요?

AI 추천 목록과 생성한 FAQ는 삭제 시 영구 삭제되며, 복구할 수 없습니다.

### FAQ 목록은 어떤 순서대로 정렬되나요?

최근 수정한 순서대로 정렬됩니다.

### FAQ 기능은 유료인가요?

FAQ 자체는 무료 플랜에서도 등록해 이용하실 수 있습니다. AI 추천은 유료 플랜에서만 이용하실 수 있어요.

### FAQ 업로드 시 템플릿에  XLSX - HTML 형식의 답변 작성할 수 있나요?

네, 채널톡 편집기에서 지원하는 HTML 태그만 사용할 수 있습니다.
지원되는 태그는 다음과 같습니다.
- <strong> 굵게
- <em> 기울임
- <a href="…"> 링크
- <ul>, <li> 글머리 기호 목록
- <code> 코드
- <pre><code></code></pre> 코드 블록
- <p> 단락

### FAQ 다운로드 후 압축 풀 때 오류가 발생해요

매니저님, 압축 해제시 문제가 발생하여 많이 불편하셨겠어요. 

FAQ가 도큐먼트 형식으로 이전되면서, zip 파일의 암호화 알고리즘에도 변경이 있었습니다.
이로 인해 일부 구버전 Windows 운영체제의 기본 압축 프로그램에서는 암호화된 파일을 제대로 처리하지 못해, 압축이 풀리지 않는 문제가 발생할 수 있습니다.

해결 방법
번거로우실 수 있으나, 7zip과 같은 외부 zip 유틸리티 프로그램을 사용해 압축을 해제해 보시기를 권장드립니다.
내부 Windows 환경에서 테스트한 결과, 7zip을 이용하면 정상적으로 압축 해제가 되는 것을 확인하였습니다.

- https://www.7zip.com/ko/
- 압축 해제하실 파일 선택 → 마우스 오른쪽 클릭 → 속성 → 7zip 선택 → 적용 후 압축 해제 해주실 수 있습니다!
