# 스페이스 만들기

Source: https://docs.channel.io/help/ko/articles/%EC%8A%A4%ED%8E%98%EC%9D%B4%EC%8A%A4-%EB%A7%8C%EB%93%A4%EA%B8%B0-54057ffd

새로운 스페이스를 만들고 기본 정보를 설정하는 방법을 알려드려요.

## Body

스페이스 만들기
스페이스가 없는 경우: 도큐먼트 화면 중앙의 '스페이스 만들기' 버튼을 클릭하여 만들 수 있어요
스페이스가 있는 경우: 도큐먼트 사이드 바 상단의 스페이스 리스트 클릭 후 '새 스페이스 만들기' 버튼을 클릭하여 만들 수 있어요.
스페이스 기본 정보 입력하기
언어
스페이스 내 아티클, 카테고리명, SEO 등의 번역을 어떤 언어로 관리할지 설정할 수 있으며, 기본 언어와 추가 언어로 구분돼요.
기본 언어: 스페이스의 기준이 되는 언어예요. 특정 단어에 번역이 없는 경우 기본 언어로 표시돼요.
추가 언어: 추가로 지원하는 언어로 언제든지 기본 언어로 변경할 수 있어요.
스페이스명
웹사이트 헤더 영역에 타이틀로 표기되어 고객에게 보여요. 언어 무관하게 공백 포함 25자까지 입력할 수 있어요.
기본 URL
스페이스를 웹사이트로 퍼블리시할 경우 사용하게 되는 기본 URL이에요. 스페이스를 먼저 생성한 후 스페이스 설정 메뉴를 통해 도메인을 커스텀할 수 있어요. 4글자 이상 16글자 이하로 입력해 주세요. (알파벳, 숫자, 하이픈(-), 언더바(_) 입력 허용)
