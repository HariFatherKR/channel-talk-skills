# 이지어드민

Source: https://docs.channel.io/help/ko/articles/%EC%9D%B4%EC%A7%80%EC%96%B4%EB%93%9C%EB%AF%BC-869393ab

카페24 앱과 이지어드민을 연동하여 주문 관리 업무를 자동화할 수 있습니다.

## Body

주요 기능
카페24와 이지어드민을 연동하여 주문 관리 업무를 자동화할 수 있습니다. 카페24 앱 태스크 중 [주문 조회]와  [주문 취소]를 이용할 수 있고 추가로 송장번호가 이미 발급된 주문에 대해서도 취소 가능 여부를 설정할 수 있습니다.
이지어드민 앱 이용 시 카페24 앱 태스크 중 [주문교환], [주문반품] 태스크는 지원되지 않습니다.
사용 방법
1. 이지어드민 앱 설치하기
[채널 설정] → [연동] → [앱스토어]에서 이지 어드민 앱을 설치해 주세요.
2. API 키 값, Shop ID 입력하기
API 파트너키
와
API 업체키
값을 입력 후 저장해 주세요.
API 키 값은 이지 어드민에서 발급받은 정보를 입력해야 합니다.
이지 어드민으로부터 Open API를 구매하신 domain_key와 partner_key를 입력해 주세요.
카페24와 연동하는 경우, 이지어드민 사이트에서 채널톡 카페24 앱에 연동된 몰의
판매처 코드
를 확인하여
Shop ID
에 입력해 주세요.
판매자 코드 확인 경로: [
이지어드민
] → [기본 정보 관리] → [판매처 관리] → [판매처 목록]
3. 카페24 허브 앱에서 WMS 설정 변경하기
경로: [채널설정] → [연동] → [앱스토어] → [카페24 허브 앱] 선택
[태스크/커맨드 설정]에서
WMS 설정
을 [이지어드민]으로 변경해 주세요.
이지 어드민 앱 설치 및 설정이 완료되지 않으면 카페24 허브 앱에서 WMS를 이지 어드민으로 변경할 수 없습니다.
반드시
이지 어드민 설치 및 설정 완료 후 카페24 허브 앱 설정
순서로 진행해 주세요.
4. 송장번호 발급 후 취소 옵션 설정하기 (선택사항)
송장번호 발급 후 취소 허용 여부
를 회사 정책에 맞게 설정해 주세요.
ON: 송장번호 발급 후에도 고객 요청 시 주문 취소 가능
OFF: 송장번호 발급 후에는 주문 취소 불가
5. 주문 취소, 주문 조회 태스크를 퍼블리시 합니다.
[
AI 메뉴] → [태스크] →  [카페24 허브 폴더] →  [주문조회], [주문취소] 태스크 > 우측 ... 버튼 클릭 > 퍼블리시 버튼을 누르면 적용됩니다.
