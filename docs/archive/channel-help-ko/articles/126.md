# 피드 연동하기

Source: https://docs.channel.io/help/ko/articles/%ED%94%BC%EB%93%9C-%EC%97%B0%EB%8F%99%ED%95%98%EA%B8%B0-00334052

인스타그램 피드 연동으로 인스타그램 계정의 최근 게시물을 채널톡 라운지에 표시 할 수 있어요. 고객이 채팅 버튼 클릭 시 피드를 확인할 수 있어 브랜드 이미지 강화에 도움됩니다.

## Body

연동 방법
설정 경로: [채널 설정] - [연동] - [메신저] - [인스타그램] 인스타그램 피드 - [연동]을 선택하세요.
새 창으로 페이스북 로그인 화면이 뜨면, 연동할 인스타그램 비즈니스 계정과 연동된 페이스북 계정으로 로그인 하세요.
[계속]을 클릭 - 연동할 페이스북 비즈니스 계정을
1개만 선택
합니다.
여러 개 선택 시 연동이 되지 않습니다.
인스타 계정과 연결된 페이스북 페이지
1개를 선택하세요. 해당 인스타그램 비즈니스 계정과 연결된 페이스북 페이지 1개만 선택
하셔야 합니다.
연동할 인스타그램 비즈니스 계정을 선택하고 [저장]을 누르세요.
연동 확인
[채널톡 채팅버튼] 클릭 - 채널톡 라운지에서 인스타그램 피드가 노출됩니다.
적용이 완료되는 데 시간이 걸릴 수 있습니다. 연동을 완료한 후에 5분 정도 기다려주세요.
연동이 완료되면, 채팅창 라운지에서 연동한 인스타그램 계정의 최신 게시물을 확인할 수 있습니다.

## FAQs

### 인스타그램 피드 연동 시 채널톡 라운지에서 보여지는 게시물의 이미지/영상 권장 비율이 있나요?

채널톡 라운지에서 보여지는 모든 이미지, 영상 비율은 인스타그램에서 업로드한 포스트 사이즈 그대로 업로드됩니다. 1:1 비율이 아닌 게시물의 경우, 공백인 곳에 검은색 여백이 생깁니다.

### 인스타그램 피드를 연동하면 원하는 게시물을 선택하여 채널톡 라운지에 표시할 수 있나요?

아쉽게도, 원하는 게시물을 선택하는 기능은 지원되지 않습니다.
인스타그램 게시물은 최근 게시물 순서대로 5개까지 보일 수 있습니다.

### 갑자기 인스타그램 연동이 끊겼어요

1.페이스북 비밀번호를 변경하면 연동이 해지됩니다.

2. 인스타그램 메신저를 연동하면 60일마다 재인증이 필요합니다.
- 재인증하지 않고 60일이 지나면 연동이 끊겨, 인스타그램에서 보낸 메시지가 채널톡으로 전송되지 않습니다.
- 연동 만료 7일 전, 해당 채널의 모든 소유자에게 채널봇이 ‘나와의 대화방’을 통해 재인증 안내를 보내드립니다.
- 또한, 페이스북 시스템상의 이유로 예고 없이 연동이 변경되거나 조기 만료되어 재인증이 필요할 수 있습니다.

3. 기존 연동 정보를 유지하려면 최초 연동 시 로그인했던 계정으로 재인증을 진행해 주세요.
- [채널 설정] → [연동] → [인스타그램 메신저] → [재인증 필요] 클릭
- 이후 새 창에서 페이스북 로그인 후 재인증을 완료하면 됩니다.
