# 슬랙

Source: https://docs.channel.io/help/ko/articles/%EC%8A%AC%EB%9E%99-9b78becd

슬랙과 채널톡을 연동하면, 상담이 인입되었을 때 슬랙으로 바로 알림이 오게 되어, 놓치지 않고 고객문의를 확인할 수 있어요.

## Body

연동 방법
설정 경로: [채널 설정] - [연동] - [기타]에서 슬랙 [설치] 를 클릭해주세요.
설치 클릭 후, 새창에서 뜨는 슬랙화면에 연동하고자 하는 1)
슬랙 워크스페이스
와 2)
알림 연동할
슬랙 채널
을 선택해주세요.
연동 확인
연동한 [슬랙 워크스페이스] - [슬랙 채널]에서 새로운 상담이 열렸다는 알림이 전송됩니다.

## FAQs

### 슬랙을 채널톡에 연동하면, 고객이 메시지를 보낼 때마다 슬랙 알림이 오나요?

새로운 상담이 열릴 때만 알림이 들어오며, 이미 열린 상담의 경우 채널톡 관리자 페이지 내에서 확인해주시기 바랍니다.

### 슬랙과 채널톡을 연동 후, 고객이 첫 메시지에 이미지를 보냈는데, 슬랙에 뜨지 않아요

이미지 메시지는 따로 슬랙에 표시되지 않습니다. 채널톡 관리자 화면에서 확인해주세요.

### 채널톡에서 슬랙을 연동하는 과정에서 오류가 발생해요

크롬과 같은 웹브라우저에서 채널톡에 접속하신 후, 동일한 브라우저에 슬랙이 로그인 되어 있는 상태로 연동을 진행해주세요.

### 슬랙 알림과 채널톡을 연동하는 것 외에 다양한 기능을 사용해 볼 수는 없나요?

슬랙 연동의 경우 상담이 최초로 생성되었을 때만 알림이 갑니다.
하지만, Webhook과 Open API를 통해 커스터마이징이 가능합니다. 자세한 사항은 개발자 문서를 참고해주세요.
- Webhook 개발자 문서
- Open API 개발자 문서
개발자 문서를 참고하여도 어려움을 느끼신다면 채널톡에 문의해주시기 바랍니다.

### 채널톡에서 슬랙이 연동되어있던 것을 해제하면 따로 슬랙으로 알림이 오나요?

채널톡에서 슬랙을 연동 해제하더라도 슬랙을 통해 알림이 별도로 오지는 않습니다.
